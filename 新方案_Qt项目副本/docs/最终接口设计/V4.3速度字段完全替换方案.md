# V4.3 速度字段完全替换方案

## 1. 结论

V4.3 协议中不再使用旧语义的 `spd / acc_v / dec_v` 工程值字段。

后续代码、GUI、查询表和流程配置应统一切换为:

```text
spd_pct
acc_pct
dec_pct
```

其协议语义为百分比:

```text
0~150
```

旧字段只允许在一次性历史数据迁移中读取，不再作为新数据、新表单、新执行路径的字段名保存。

## 2. V4.3 文档依据

V4.3 在以下函数中明确使用百分比字段:

| 函数 | 地址 | 字段 | 值域 |
|------|------|------|------|
| Func106 | IEEE(6) | spd_pct | FLOAT 0~150 |
| Func106 | IEEE(8) | acc_pct | FLOAT 0~150 |
| Func106 | IEEE(10) | dec_pct | FLOAT 0~150 |
| Func107 | IEEE(6) | spd_pct | FLOAT 0~150 |
| Func107 | IEEE(8) | acc_pct | FLOAT 0~150 |
| Func107 | IEEE(10) | dec_pct | FLOAT 0~150 |
| Func108 | IEEE(14) | spd_pct | FLOAT 0~150 |
| Func108 | IEEE(16) | acc_pct | FLOAT 0~150 |
| Func108 | IEEE(18) | dec_pct | FLOAT 0~150 |
| Func11 | IEEE(14) | spd_pct | FLOAT 0~150 |
| Func11 | IEEE(16) | acc_pct | FLOAT 0~150 |
| Func11 | IEEE(18) | dec_pct | FLOAT 0~150 |

报警定义:

```text
LONG(38).03 = 速度超限
LONG(38).04 = 加速度超限
LONG(38).05 = 减速度超限
```

模糊参数章节补充:

```text
fuzzy_spd/fuzzy_acc/fuzzy_dec = 1 时，输入百分比可以为负。
最终结果限制在 0~150。
```

## 3. 修改目标

### 3.1 字段命名目标

替换前:

```text
spd
acc_v
dec_v
```

替换后:

```text
spd_pct
acc_pct
dec_pct
```

### 3.2 值域目标

Func11:

```text
0 <= spd_pct <= 150
0 <= acc_pct <= 150
0 <= dec_pct <= 150
```

Func106 / Func107 / Func108:

```text
fuzzy_xxx = 0:
  0 <= xxx_pct <= 150

fuzzy_xxx = 1:
  输入 xxx_pct 可为负
  最终值 = 当前百分比 + 输入百分比
  最终值限制在 0~150
```

## 4. 修改范围

### 4.1 数据模型

修改 `robot_modbus_lite/models.py`:

- `QueryRecord.speed_value()` 改为 `spd_pct_value()`。
- `QueryRecord.acc_value()` 改为 `acc_pct_value()`。
- 新增或改造 `dec_pct_value()`。
- `SixAxisCommand` 字段改为:

```python
spd_pct: float = 0.0
acc_pct: float = 0.0
dec_pct: float = 0.0
```

- `to_func_writes()` 写入地址不变，只替换字段来源。

### 4.2 查询表加载和保存

修改 `robot_modbus_lite/query_table.py`:

- 默认参数从旧字段改为新字段:

```python
"spd_pct": 50.0
"acc_pct": 60.0
"dec_pct": 60.0
```

- JSON 保存时只保存新字段。
- `save_query_table_json()` 保存前必须统一归一化 `record.params`:
  - 删除 `spd / acc_v / dec_v`
  - 输出 `spd_pct / acc_pct / dec_pct`
  - 防止旧字段通过直接序列化 `QueryRecord.params` 再次写回 JSON
- CSV/JSON 加载时支持一次性兼容旧字段并转换。

兼容读取规则:

```text
优先读取 spd_pct / acc_pct / dec_pct。
如果不存在，再读取旧 spd / acc_v / dec_v。
读取旧字段后立即迁移为新字段。
```

### 4.3 GUI 表单

修改 `robot_modbus_lite/qt_gui.py`:

- 控件变量建议改名:

```text
spd_edit   -> spd_pct_edit
acc_v_edit -> acc_pct_edit
dec_v_edit -> dec_pct_edit
```

- 表单显示改为:

```text
速度百分比 (spd_pct)
加速度百分比 (acc_pct)
减速度百分比 (dec_pct)
```

- 结构化 JSON 预览只输出新字段。
- 新增/保存模板时不再生成旧字段。

### 4.4 服务层

修改 `robot_modbus_lite/service.py`:

- `build_six_command_from_record()` 全部读取 `spd_pct / acc_pct / dec_pct`。
- 不再把旧字段作为主路径。
- 如保留历史兼容，只允许通过 query table 迁移层完成，不在 service 层继续散落旧字段判断。

### 4.5 mock 控制器

修改 `mock_controller/controller.py`:

- Func106/107/108/11 按 V4.3 百分比语义校验。
- Func11 严格 `0~150`。
- Func106/107/108:
  - 绝对模式严格 `0~150`。
  - 叠加模式允许输入负值。
  - 最终值 clamp 到 `0~150`。
- 超范围时按协议写 `LONG(38).03/.04/.05`。

## 5. 历史数据迁移方案

新增迁移脚本，建议路径:

```text
tools/migrate_v43_pct_fields.py
```

迁移对象:

```text
data/query_table.json
data/flows.json
dist/RobotModbusLite/_internal/data/query_table.json
打包输出/dist/RobotModbusLite/_internal/data/query_table.json
build_output/dist/RobotModbusLite V3.0/_internal/data/query_table.json
```

实现时建议脚本递归扫描:

```text
**/query_table.json
**/flows.json
```

并排除:

```text
**/exported_logs/**
```

迁移规则:

```text
如果旧值 <= 150:
  原样迁移

如果旧值 > 150:
  spd_pct = 50
  acc_pct = 60
  dec_pct = 60
```

原因:

```text
旧工程值 300/400/600 没有可靠比例，不能自动猜测换算。
统一替换为安全默认百分比更可控。
```

迁移示例:

替换前:

```json
{
  "spd": 300,
  "acc_v": 400,
  "dec_v": 400
}
```

替换后:

```json
{
  "spd_pct": 50,
  "acc_pct": 60,
  "dec_pct": 60
}
```

## 6. 删除旧字段残留

```text

acc_v

```

允许保留的旧字段位置:


不允许保留的旧字段位置:

```text

```

## 7. 验收标准

1. 新建 Func106/107/108/11 模板时，只出现 `spd_pct / acc_pct / dec_pct`。
2. 保存后的 `query_table.json` 不再包含 `spd / acc_v / dec_v`。
3. Func106/107/108 写入地址不变:
   - `IEEE(6/8/10)` 或 `IEEE(14/16/18)`。
4. Func11 写入地址不变:
   - `IEEE(14/16/18)`。
5. `0~150` 外的绝对模式参数会被 GUI 拦截。
6. Func11 的 `0~150` 外参数会被 GUI 拦截。
7. fuzzy 叠加模式允许负输入，但最终值限制在 `0~150`。
8. mock 对超限参数写入正确报警位:
   - `LONG(38).03/.04/.05`。
9. 旧 JSON 经过迁移后可正常加载、保存、执行。
10. `python -m compileall robot_modbus_lite mock_controller` 通过。

## 8. 风险和注意事项

1. 这是破坏性字段改名，必须同步迁移历史数据。
2. 旧流程配置中如果嵌入了 `spd / acc_v / dec_v`，也必须迁移。
3. 如果直接删除旧字段读取，未迁移数据会丢失速度参数。
4. 旧工程值不能自动按比例换算，建议按安全默认值替换。
5. 真实硬件上仍需确认固件是否已经完全按 V4.3 百分比语义执行。

## 9. 建议实施顺序

1. 修改数据模型字段。
2. 修改 query table 默认参数和加载保存。
3. 修改 service 层命令构建。
4. 修改 GUI 表单、预览、校验和保存。
5. 修改 mock 百分比/fuzzy 规则。
6. 编写并运行历史数据迁移脚本。
7. 全局搜索并清理旧字段残留。
8. 运行编译、mock 冒烟、GUI 冒烟。
9. 上真实控制器前做 M0.5 地址映射和百分比语义验证。
