# 机械手上位机通信开发说明书

## V3.0  2026-04-24

---

## 一、函数号规划

| 号段 | 使用者 | 说明 |
|------|--------|------|
| 1~30 | 触摸屏(HMI) | 出厂调试、标定、点动，上位机不用 |
| **101~120** | **上位机** | **上位机专用函数，从101开始** |

上位机只使用101~106，共6个函数。

---

## 二、通信规则

```
上位机写:  IEEE(0)=函数号  →  IEEE(2~30)=参数  →  IEEE(32)=1触发
下位机读:  IEEE(34)=状态   ←  BIT(243)=总报警  ←  IEEE(2~30)=返回值(Func105)
```

**三条规则**:
1. IEEE(0)不清零 — 函数号保持，改了才变
2. IEEE(32)=1触发 — 每写1执行一次
3. 连续执行 — 改参数+触发即可

**发指令前必须检查**:
- BIT(243)=0 (无报警)
- IEEE(34)=0或4 (不在执行中)

## 三、6个函数定义

### 101 关节移动

| IEEE | 类型 | 说明 |
|------|------|------|
| 2 | int | 轴号 0~5 (J1~J6) |
| 4 | int | 方向 1=正 -1=反 |
| 6 | float | 速度(度/s)，0=默认100 |
| 8 | float | 角度(度)，始终正数 |
| 10 | int | **模糊标志**: 0=精确 1=模糊(限10度) |

### 102 直线插补运动

| IEEE | 类型 | 说明 |
|------|------|------|
| 2 | float | 目标X (mm) |
| 4 | float | 目标Y (mm) |
| 6 | float | 目标Z (mm) |
| 8 | float | 目标Rx (度) |
| 10 | float | 目标Ry (度) |
| 12 | float | 目标Rz (度) |
| 14 | float | 速度(mm/s)，0=默认3000 |
| 16 | float | 加速度，0=默认1000 |
| 18 | float | 减速度，0=默认1000 |
| 20 | int | **模糊标志**: 0=精确 1=模糊 |
| 22 | float | **模糊最大步长**(mm)，0=默认10 |

**模糊安全**: IEEE(20)=1时，若位移>IEEE(22)，拒绝执行，返回IEEE(34)=72

### 103 报警清除

无参数。清除所有报警，5秒保护期。

### 104 停止

| IEEE | 类型 | 说明 |
|------|------|------|
| 2 | int | 0=急停 1=慢停 |

也可直接写BIT(150)=1触发急停。

### 105 状态查询

无输入参数。触发后读取IEEE(2~30)获取:

| IEEE | 说明 |
|------|------|
| 2 | 当前X (mm) |
| 4 | 当前Y (mm) |
| 6 | 当前Z (mm) |
| 8 | 当前Rx (度) |
| 10 | 当前Ry (度) |
| 12 | 当前Rz (度) |
| 14~24 | 当前J1~J6 (度) |
| 26 | R3d距离 (mm) |
| 28 | Z高度 (mm) |
| 30 | 主报警码 |

**主报警码** (位组合):

| 值 | 含义 |
|---|------|
| 0 | 正常 |
| 1 | 半径超限 |
| 2 | 高度超限 |
| 4 | 轴驱动器报警 |
| 8 | 限位超限 |
| 16 | 速度超限 |
| 32 | 指令非法(模糊步长过大) |

## 四、状态反馈

### IEEE(34) 函数状态

| 值 | 含义 | 上位机动作 |
|----|------|-----------|
| 0 | 空闲 | 可发指令 |
| 1 | 就绪 | 可发指令 |
| 2 | 执行中 | 等待 |
| 4 | 完成 | 可发新指令 |
| 12 (4+8) | 完成+报警 | 清除报警 |
| 28 (4+8+16) | 完成+半径超限 | 反向移动 |
| 44 (4+8+32) | 完成+高度超限 | 反向移动 |
| 72 (8+64) | 报警+指令非法 | 减小步长 |

### BIT(243) 总报警标志

**最重要！每次发运动指令前必须检查。**
- 0=正常 1=有报警，禁止运动

### 实时数据 (持续更新，随时可读)

| IEEE | 说明 |
|------|------|
| 1500~1510 | J1~J6角度 |
| 1512~1522 | X/Y/Z/Rx/Ry/Rz坐标 |
| 1700~1706 | 安全参数(R_min/R_max/Z_min/Z_max) |
| 1740 | 当前R3d距离 |
| 1742 | 当前Z高度 |

## 五、模糊指令对接

上位机解析语音/自然语言→Func102参数:

| 用户指令 | 上位机处理 | 模糊标志 | 最大步长 |
|---------|-----------|---------|---------|
| 上/下一点 | Z±5mm | 1 | 10 |
| 前/后一点 | X±5mm | 1 | 10 |
| 左/右一点 | Y±5mm | 1 | 10 |
| 上N毫米 | Z+N | 1 | 10 |
| 快/慢一点 | 速度×1.2/0.8 | 1 | 10 |
| 到(x,y,z) | 精确坐标 | 0 | - |
| 快停 | BIT(150)=1 | - | - |
| 慢停 | Func104,参数=1 | - | - |

**核心**: 模糊指令必须设IEEE(20)=1，下位机自动限制步长。精确指令设0，不做步长限制。

---

## 六、典型流程

```
启动: 等待BIT(253)=1 → 检查BIT(243)=0 → 可发指令

精确移动:
  IEEE(0)=102, IEEE(2~18)=位置+速度, IEEE(20)=0, IEEE(32)=1
  等待IEEE(34)=4

模糊指令"上一点":
  读当前位置IEEE(1512~1522)
  IEEE(6)=Z+5, 其他不变
  IEEE(20)=1, IEEE(22)=10, IEEE(32)=1
  若IEEE(34)=72 → 步长过大，减小重试

急停: BIT(150)=1

报警处理:
  BIT(243)=1 → Func105查状态 → 处理 → Func103清报警 → 等5秒
```
