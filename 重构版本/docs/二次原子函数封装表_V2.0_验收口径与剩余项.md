# 二次原子函数封装表 V2.0 验收口径与剩余项

更新时间：2026-05-22

## 结论

当前实现应按两个口径验收：

| 口径 | 范围 | 完成度 | 结论 |
|---|---|---:|---|
| A：Qt 离线侧 | 自然语言解析、原子记忆、QueryRecord 生成、Qt 确认页、归档、能力查询、保护性拒绝 | 约 97% | 可作为当前阶段完成口径 |
| B：真机交付侧 | 真实控制器回显、运动完成验证、FRAME_TRANS2、Func11 连续插补、现场阈值压测 | 约 80%~85% | 需要真机联调关闭 |

口径 A 不包含 Web API / HTML 页面，也不包含真实控制器联调。

| 能力 | 验收方式 | 状态 |

| J/V/C/D/IO 原子命令 | 可解析为 Func106/107/108/110/120 的动态 QueryRecord | 完成 |
| 位置库 | 保存当前位置、移动到位置、查询位置、删除位置 | 基础完成 |

| GUI 能力查询 | 用户可问“现在支持哪些原子命令”获得能力摘要 | 完成 |

## A 口径剩余

| 项目 | 当前处理 | 为什么不继续在离线阶段扩展 |
|---|---|---|
| 位置栈精确回退 | 现有位置栈可用，但填充依赖执行结果 | 需要真机或 mock 执行后位置回写才能精确 |
| Q08 完整可达性 | 当前是 XYZ 软限位 + 当前执行条件 | 完整结论需要 L2 逆解和路径预演 |
| 复杂条件/循环/并行 | 当前保护性拒绝 | 需要流程编排语义、取消策略和失败回滚策略 |
| 风险阈值精调 | 当前按保守阈值实现 | 需要现场速度、步长、载荷、夹具工况校准 |

这些项不阻塞当前 Qt 离线侧验收。

## B 口径待真机关闭

| 项目 | 需要的现场验证 | 关闭条件 |
|---|---|---|
| Func106/107/108 动作边界 | 真机执行低速小步长、高速、大步长、绝对位姿动作 | 回显、执行完成、报警行为与预期一致 |
| Func110 延时 | 真机执行秒级/毫秒级延时 | 参数地址、剩余时间、完成状态一致 |
| Func120 IO | 真机执行 IO 开关 | IO 点号、动作方向、互斥行为一致 |
| Q08 完整可达性 | 接入 `FRAME_TRANS2` 或等价逆解 | 目标点回答能区分软限位、逆解失败、奇异风险 |
| Func11 连续插补 | 明确路径格式、点表写入、速度/加速度约束 | 先完成协议确认，再开放执行 |
| 风险阈值 | 结合载荷、速度、现场工艺调整 | 阈值写入配置并通过现场试运行 |
| 位置历史 | 执行后位置快照稳定写入位置栈 | “返回上一步”能回到真实上一执行位置 |
