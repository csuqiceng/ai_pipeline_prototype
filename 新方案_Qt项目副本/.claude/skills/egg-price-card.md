# 鸡蛋价格卡片生成器

## 触发条件

用户提供鸡蛋价格行情数据，并要求生成价格卡片。触发词：鸡蛋价格、价格卡片、egg price card。

## 输入

接受以下任一形式的原始数据：
1. **图片**：类似第一张图的完整行情表
2. **文本表格**：包含品种价格和重量标准价格的文本格式
3. **JSON**：结构化数据

## 数据提取规则

### 卡片一：品种零售价卡片

从原始数据的**左上角品种表**提取以下字段：

| 原始字段 | 卡片字段 | 说明 |
|---------|---------|------|
| 品种名称 | 品种 | 粉壳蛋、褐壳蛋、富硒蛋、保洁蛋等 |
| 价格数值 | 价格(元/斤) | 直接取值 |
| ↑/↓ + 数值 | 较昨日 | 转换规则见下方 |
| ↑/↓ 方向 | 涨跌 | 转换规则见下方 |

### 卡片二：重量标准批发价卡片

从原始数据**主表的第一列 + 最后两列**提取：

| 原始列 | 卡片字段 | 说明 |
|-------|---------|------|
| 重量标准列 | 360枚/箱 净重 | 如 44、43、42...33以下 |
| 报价列 | 价格(元/箱) | 如 176、174...155 |
| 对比列（↓/↑） | 较昨日 | 转换规则见下方 |
| 对比列方向 | 涨跌 | 转换规则见下方 |

## 涨跌转换规则

| 原始状态 | 较昨日列 | 涨跌列 |
|---------|---------|--------|
| 上涨（↑ / 红字） | `+数值`（如 +0.1） | 红色 **涨** |
| 下跌（↓ / 绿字） | `-数值`（如 -0.1、-2） | 绿色 **跌** |
| 持平（无变化） | `0` | 黑色 **稳** |

## 卡片视觉规范

### 共用样式
- 圆角矩形卡片
- 背景色：浅米色/暖色调（#FFF8F0）
- 表头行：橙色背景（#FF8C00），白色文字
- 数据行：浅米色背景
- 表格边框：浅灰色细线

### 卡片一（品种零售价）表头图标
鸡蛋图标 + 计算器图标 + 购物篮图标

### 卡片二（重量标准批发价）表头图标
货车图标 + 计算器图标 + 购物篮图标

### 卡片二底部要求栏
显示固定文本：`要求：无药残、无双黄、脏蛋、裂纹沙壳`

## 输出

调用 `egg_price_card/generator.py` 生成 HTML 文件，或直接输出 HTML 代码。

### 使用方式

```bash
# 从 JSON 数据生成
python egg_price_card/generator.py --input data.json --output cards.html

# 从图片生成（需要先 OCR 提取数据）
# 1. 先手动或用工具从图片提取数据到 JSON
# 2. 再运行 generator.py
```

    {"name": "富硒蛋", "price": 3.85, "change": -0.1},
    {"name": "保洁蛋", "price": 4.1, "change": -0.1}

## 执行步骤

1. 识别输入类型（图片/文本/JSON）
2. 若为图片，先分析提取数据，转为 JSON 格式
3. 调用 `egg_price_card/generator.py` 生成 HTML
4. 展示生成的卡片 HTML 或在浏览器中打开
