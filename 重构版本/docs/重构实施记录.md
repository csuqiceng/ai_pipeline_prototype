## 第二阶段：主窗口职责拆分

### 已完成

在第一阶段基础上继续拆分 `RobotQtWindow`，将主窗口中的高风险职责迁移到独立 mixin。当前 `qt_gui.py` 保留 UI 构建、表单、模板编辑和少量校验逻辑，其余运行职责已拆到模块中。

新增模块：

| 模块 | 职责 |
|---|---|
| `gui_logging.py` | 日志上下文、dispatch id、日志持久化、日志表刷新、异常日志字段。 |
| `six_axis_command_mixin.py` | V4.3 六轴发送链路：前置检查、回显校验、参数重写、触发、等待完成、Func104 后置确认、六轴反馈读取。 |
| `controller_runtime_mixin.py` | 控制器连接缓存、断开、实时轮询、后台线程入口、主线程回调。 |
| `gui_system_mixin.py` | 系统按钮、系统命令发送、传统系统状态 UI 更新、反馈读取和反馈值应用。 |
| `voice_mixin.py` | 讯飞客户端检测、worker 子进程、麦克风设备、代理/本地识别、`MicStreamThread` 内部类。 |
| `flow_execution_mixin.py` | 流程启动前就绪检测、自动/单步流程、并行组执行、流程完成/失败回调。 |
| `nlp_mixin.py` | 自然语言解析、DeepSeek/规则解析、NLP 计划执行。 |
| `command_dispatch_mixin.py` | 单条模板指令发送编排、执行计划调度、发送后状态/历史/日志更新。 |
| `avoidance_execution_mixin.py` | 安全中间点规避计划、当前机器人坐标读取、规避中间点记录构造。 |

### 当前边界

- `qt_gui.py` 仍是 Qt 主窗口和 UI 组装入口。
- `qt_gui.py` 现在通过多 mixin 组合运行能力：
  `CommandDispatchMixin -> AvoidanceExecutionMixin -> NlpMixin -> FlowExecutionMixin -> VoiceMixin -> GuiSystemMixin -> ControllerRuntimeMixin -> SixAxisCommandMixin -> GuiLoggingMixin -> QMainWindow`
- V4.3 协议、流程、语音、日志、后台线程已经不再直接堆在 `RobotQtWindow` 文件主体中。

### 保持不变

- 主入口仍为 `gui_main.py`。
- JSON 数据格式未改。
- mock/real 控制器接口未改。
- V4.3 发送顺序未改。
- 语音 worker 文件 IPC 语义未改。
- GUI 页面结构和按钮连接未改。
