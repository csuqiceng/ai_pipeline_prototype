# 最终标准协议寄存器通信示意图

## 1. 总体流程

```text
┌──────────────────────────────────────────────────────────────┐
│                         上位机 Qt                           │
│  自然语言/按钮/后台模板                                      │
│  生成标准命令 JSON                                           │
└──────────────────────────────────────────────────────────────┘
                              │
                              │ 组包
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                    指令区 VR[0] ~ VR[15]                    │
├────────┬───────────────┬─────────────────────────────────────┤
│ VR[0]  │ CMD_CODE      │ 命令码                              │
│ VR[1]  │ TASK_ID       │ 任务号                              │
│ VR[2]  │ POS_X         │ X                                   │
│ VR[3]  │ POS_Y         │ Y                                   │
│ VR[4]  │ POS_Z         │ Z                                   │
│ VR[5]  │ ROT_RX        │ RX                                  │
│ VR[6]  │ ROT_RY        │ RY                                  │
│ VR[7]  │ ROT_RZ        │ RZ                                  │
│ VR[8]  │ SPD_PCT       │ 速度百分比                          │
│ VR[9]  │ ACC_PCT       │ 加速度百分比                        │
│ VR[10] │ DEV_ID        │ 设备/工位ID                         │
│ VR[11] │ IO_GRIP       │ 夹爪动作                            │
│ VR[12] │ IO_DOOR       │ 门动作                              │
│ VR[13] │ EXT_P1        │ 扩展参数1                           │
│ VR[14] │ EXT_P2        │ 扩展参数2                           │
│ VR[15] │ SAFETY_LV     │ 安全等级                            │
└────────┴───────────────┴─────────────────────────────────────┘
                              │
                              │ 写入寄存器
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                      下位机快速镜像任务                        │
│  读取 VR[0]~VR[15]                                            │
│  把命令原样复制到镜像区 VR[500]~VR[515]                        │
└──────────────────────────────────────────────────────────────┘
                              │
                              │ 上位机每100ms轮询镜像区并比对
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                    镜像区 VR[500] ~ VR[515]                 │
├────────┬───────────────┬─────────────────────────────────────┤
│ 用途   │ MIRROR        │ 下位机收到的原始命令镜像             │
└────────┴───────────────┴─────────────────────────────────────┘
                              │
                              │ 镜像一致则发执行触发
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                    执行触发 VR[517]                         │
├────────┬───────────────┬─────────────────────────────────────┤
│ VR[517]│ EXEC_TRIG     │ 上位机写1，下位机执行后自清零        │
└────────┴───────────────┴─────────────────────────────────────┘
                              │
                              │ 下位机执行
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                         下位机控制器                         │
│  解析命令码 + 参数                                             │
│  执行动作：MOVE / IO / WAIT / RESET 等                         │
│  执行中做范围校验 / 安全校验 / 报警处理                         │
│  回写结果区和实时监控区                                         │
└──────────────────────────────────────────────────────────────┘
                              │
                              │ 读取反馈
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                         上位机 Qt                           │
│  更新：执行结果 / 忙闲状态 / 当前坐标 / 报警 / IO状态         │
│  写入日志 / 刷新页面显示                                       │
└──────────────────────────────────────────────────────────────┘
```

## 2. 单条命令示例

### 2.1 MOVE_ABS 指令下发

```text
上位机写：
VR[0]  = 1001
VR[1]  = 1001
VR[2]  = 120.5
VR[3]  = 80.0
VR[4]  = 45.0
VR[5]  = 0.0
VR[6]  = 0.0
VR[7]  = 0.0
VR[8]  = 30
VR[9]  = 40
VR[10] = 2
VR[11] = 0
VR[12] = 0
VR[13] = 0
VR[14] = 0
VR[15] = 5
```

### 2.2 镜像确认与执行触发

```text
下位机镜像：
VR[500] ~ VR[515] = 上位机刚刚写入的 VR[0] ~ VR[15]

上位机每100ms读取一次 VR[500]~VR[515]
如果连续 3~5 次都与原命令不一致：
  判定通讯故障

如果镜像一致：
  上位机写 VR[517] = 1
  下位机开始执行
  下位机执行后自行清零 VR[517]
```

### 2.3 下位机执行后回写

```text
VR[16] = 0
VR[17] = 0
VR[18] = 120.5
VR[19] = 80.0
VR[20] = 45.0
VR[21] = 0.0
VR[22] = 0.0
VR[23] = 0.0
VR[24] = 0
VR[25] = 0
```

## 3. 说明

- 上位机负责把命令组织成固定字段，写入 `VR[0]~VR[15]`
- 下位机快速通信任务负责把命令镜像到 `VR[500]~VR[515]`
- 上位机通过轮询镜像区确认下位机已收到完整命令
- 镜像一致后，上位机再写 `VR[517]` 触发执行
- 下位机负责执行动作，并回写 `VR[16]~VR[25]`
- 上位机再读取状态区，用于页面显示、日志记录和报警提示
- 当前 Qt 项目中：
  - 最终标准协议已经支持这套组包、镜像确认和状态解析
  - 模拟控制器已经支持这套本地闭环验证
  - 真实下位机最终是否完全按此协议运行，还需现场联调确认
