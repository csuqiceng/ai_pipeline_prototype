## 一、问题分析

### 1.1 当前架构

```
当前架构：
┌─────────────────┐
│   客户端 .env    │ ← API Key 明文存储，打包后暴露
├─────────────────┤
│ DeepSeek API    │ ← 直接调用，你方付费
│ 讯飞 API        │ ← 直接调用，你方付费
└─────────────────┘
```

### 1.2 风险点

- `.env` 文件打包后可被提取
- 所有用户共享你的 API Key
- 无法控制使用额度
- 无法区分免费/付费用户

## 三、产品方案

### 3.1 三种使用模式

| 模式 | 说明 | 你方成本 |
|------|------|----------|
| **免费模式** | DeepSeek/语音关闭，仅本地规则解析 | 无 |
| **自带 Key 模式** | 用户配置自己的 API Key，软件只做调用 | 无 |
| **订阅解锁模式** | 用户购买授权码，使用你方统一 API | 有 (按用量) |

### 3.2 授权策略

- 授权码 = 绑定机器码 + 到期时间 + 权限范围
- 权限范围:
  - `voice_enabled` - 语音功能开关
  - `deepseek_enabled` - DeepSeek 功能开关
  - `monthly_quota` - 月度配额
  - `daily_quota` - 每日配额
- 授权码支持在线校验 + 本地缓存（断网可用 7 天）

### 3.3 订阅类型

| 类型 | 有效期 | 功能 | 适用场景 |
|------|--------|------|----------|
| 试用版 | 7-30天 | 全功能体验 | 新用户试用 |
| 月度订阅 | 30天 | 按需配置 | 短期项目 |
| 年度订阅 | 365天 | 优惠价格 | 长期用户 |
| 永久授权 | 永久 | 全功能 | 一次性购买 |

### 3.4 模式优先级与切换规则

#### 3.4.1 优先级规则

**当用户同时配置了自带 Key 和激活了授权码时，按以下优先级处理：**

| 优先级 | 模式 | 判断条件 | 说明 |
|--------|------|----------|------|
| 1 | 订阅模式 | 授权有效且功能已启用 | 优先使用订阅配额 |
| 2 | 自带 Key | .env 配置了 API Key | 订阅无效时降级 |
| 3 | 免费模式 | 以上均不满足 | 仅本地规则解析 |

#### 3.4.2 功能级优先级

```python
def get_api_client(license_manager, feature: str):
    """
    获取 API 客户端（按优先级）
    
    优先级逻辑:
    1. 检查订阅授权是否有效且功能已启用 → 使用代理模式
    2. 检查本地 .env 是否配置了 API Key → 使用直连模式
    3. 以上都不满足 → 返回 None（降级到免费模式）
    """
    status = license_manager.check_status()
    
    if feature == 'deepseek':
        if status.deepseek_enabled:
            can_use, _ = license_manager.can_use_deepseek()
            if can_use:
                return DeepSeekClient.from_license(license_manager)
        
        try:
            return DeepSeekClient.from_env()
        except ValueError:
            return None
    
    elif feature == 'voice':
        if status.voice_enabled:
            can_use, _ = license_manager.can_use_voice()
            if can_use:
                return IFlytekIATClient.from_license(license_manager)
        
        try:
            config = IFlytekIATConfig.from_env()
            return IFlytekIATClient(config)
        except IFlytekRTASRError:
            return None
    
    return None
```

### 4.4 配额统计查询

**重要：使用时区时间窗查询，避免数据库时区影响**

```python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

SERVER_TIMEZONE = ZoneInfo("Asia/Shanghai")

def get_usage_period(period: str, tz: ZoneInfo = SERVER_TIMEZONE) -> tuple[datetime, datetime]:
    """
    获取统计周期的时间范围（UTC）
    
    Args:
        period: 'daily' 或 'monthly'
        tz: 时区（默认北京时间 UTC+8）
    
    Returns:
        (start_time, end_time) UTC 时间
    """
    now = datetime.now(tz)
    
    if period == 'daily':
        start = now.replace(hour=0, minute=0, second=0, microsecond=0)
        end = start + timedelta(days=1)
    elif period == 'monthly':
        start = now.replace(day=1, hour=0, minute=0, second=0, microsecond=0)
        if now.month == 12:
            end = start.replace(year=now.year + 1, month=1)
        else:
            end = start.replace(month=now.month + 1)
    else:
        raise ValueError(f"Unknown period: {period}")
    
    return start.astimezone(timezone.utc), end.astimezone(timezone.utc)


def get_daily_usage(db, license_id: int, service_type: str) -> int:
    """查询今日使用量"""
    start, end = get_usage_period('daily')
    return db.query(func.count(UsageLog.id)).filter(
        UsageLog.license_id == license_id,
        UsageLog.service_type == service_type,
        UsageLog.created_at >= start,
        UsageLog.created_at < end,
        UsageLog.status == 'success'
    ).scalar() or 0


def get_monthly_usage(db, license_id: int, service_type: str) -> int:
    """查询本月使用量"""
    start, end = get_usage_period('monthly')
    return db.query(func.count(UsageLog.id)).filter(
        UsageLog.license_id == license_id,
        UsageLog.service_type == service_type,
        UsageLog.created_at >= start,
        UsageLog.created_at < end,
        UsageLog.status == 'success'
    ).scalar() or 0
```

#### 4.5.1 幂等性保证

```python
def log_usage(db, license_id: int, service_type: str, request_id: str, **kwargs) -> bool:
    """
    记录使用量（幂等）
    
    - request_id 由客户端生成（UUID v4）
    - 数据库 UNIQUE 约束保证同一请求只记录一次
    - 重试请求会被忽略（返回已存在的记录）
    """
    try:
        log = UsageLog(
            license_id=license_id,
            service_type=service_type,
            request_id=request_id,
            **kwargs
        )
        db.add(log)
        db.commit()
        return True
    except IntegrityError:
        db.rollback()
        existing = db.query(UsageLog).filter(
            UsageLog.request_id == request_id
        ).first()
        return existing is not None
```

#### 4.5.2 跨时区处理

时区处理逻辑已在 [4.4 配额统计查询](#44-配额统计查询) 中定义，核心要点：

- **存储时区**：数据库统一使用 UTC 时间
- **显示时区**：按服务器配置（默认 Asia/Shanghai）
- **统计周期**：使用 `[start, end)` 左闭右开区间
- **索引优化**：`created_at >= start AND created_at < end` 可利用索引

#### 4.5.3 重试与失败处理

| 场景 | 处理方式 |
|------|----------|
| 客户端重试相同请求 | request_id 相同，数据库忽略重复记录 |
| 上游服务失败 | status='failed'，不计入配额 |
| 网络超时重试 | request_id 保证幂等，不会重复计费 |
| 配额同步失败 | 心跳时重试同步，本地缓存配额快照 |

## 五、授权码生成规则

### 5.1 格式设计

```
授权码格式: XXXX-XXXX-XXXX-XXXX-XXXX (25字符)

结构:
- 前4字符: 产品标识 (如 RMLT = RobotModbusLite)
- 中间16字符: 随机唯一标识
- 后4字符: HMAC签名校验码 (服务端验证)

示例: RMLT-ABCD-EFGH-IJKL-MNOP-1A2B
```

### 5.2 安全机制

**核心原则：服务端签名，服务端验证，客户端不持密钥**

| 机制 | 说明 |
|------|------|
| HMAC-SHA256签名 | 使用服务端私钥对授权码签名 |
| 签名密钥 | 仅存储在服务端，不暴露给客户端 |
| 校验位置 | 激活时服务端验证签名有效性 |
| 防伪造 | 无密钥无法生成有效授权码 |
| 防撞库 | 签名空间 2^32，暴力枚举成本极高 |

### 5.3 生成代码（服务端）

```python
import secrets
import hashlib
import hmac
import base64

LICENSE_SIGNING_KEY = "your-secret-signing-key-min-32-chars"

def generate_license_code() -> str:
    prefix = "RMLT"
    
    random_bytes = secrets.token_bytes(12)
    random_part = base64.b32encode(random_bytes).decode('ascii')[:16]
    
    payload = f"{prefix}-{random_part[:4]}-{random_part[4:8]}-{random_part[8:12]}-{random_part[12:16]}"
    
    signature = hmac.new(
        LICENSE_SIGNING_KEY.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()[:4].upper()
    
    return f"{payload}-{signature}"


def verify_license_code(license_code: str) -> bool:
    if not license_code or len(license_code) != 29:
        return False
    
    parts = license_code.split('-')
    if len(parts) != 6 or parts[0] != 'RMLT':
        return False
    
    payload = '-'.join(parts[:5])
    provided_signature = parts[5]
    
    expected_signature = hmac.new(
        LICENSE_SIGNING_KEY.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()[:4].upper()
    
    return hmac.compare_digest(provided_signature, expected_signature)
```

### 5.4 密钥管理

```yaml
生产环境:
  - 密钥存储: 环境变量或密钥管理服务 (如 AWS Secrets Manager)
```

```python
from fastapi import Request, HTTPException
from collections import defaultdict
import time

class RateLimiter:
    def __init__(self):
        self.requests = defaultdict(list)
    
    def check_rate_limit(
        self, 
        key: str, 
        max_requests: int = 60, 
        window_seconds: int = 60
    ) -> bool:
        now = time.time()
        requests = self.requests[key]
        
        requests[:] = [t for t in requests if now - t < window_seconds]
        
        if len(requests) >= max_requests:
            return False
        
        requests.append(now)
        return True

rate_limiter = RateLimiter()

RATE_LIMITS = {
    "/api/v1/auth/activate": {"max": 5, "window": 300},
    "/api/v1/auth/heartbeat": {"max": 20, "window": 60},
    "/api/v1/proxy/deepseek/chat": {"max": 60, "window": 60},
    "/api/v1/proxy/voice/transcribe": {"max": 30, "window": 60},
}

@app.middleware("http")
async def rate_limit_middleware(request: Request, call_next):
    if request.url.path in RATE_LIMITS:
        limit = RATE_LIMITS[request.url.path]
        client_id = request.headers.get("X-Client-ID", request.client.host)
        key = f"{request.url.path}:{client_id}"
        
        if not rate_limiter.check_rate_limit(key, limit["max"], limit["window"]):

                detail={
                    "code": 4001,
                    "message": "请求过于频繁，请稍后再试",
                    "retry_after": limit["window"]
                }
            )
```

#### 6.3.3 重放防护（Nonce + Timestamp）

```python
import time
from collections import OrderedDict

NONCE_CACHE = OrderedDict()
NONCE_CACHE_SIZE = 10000
NONCE_EXPIRE_SECONDS = 300

def _cleanup_expired_nonces():
    """清理过期的 nonce（在每次检查时调用）"""
    now = int(time.time())
    expired_keys = [
        nonce for nonce, ts in NONCE_CACHE.items()
        if now - ts > NONCE_EXPIRE_SECONDS
    ]
    for key in expired_keys:
        del NONCE_CACHE[key]

def verify_request_signature(
    timestamp: str,
    nonce: str,
    signature: str,
    body: str,
    secret: str
) -> bool:
    now = int(time.time())
    ts = int(timestamp)
    
    if abs(now - ts) > 300:
        return False
    
    expected = hmac.new(
        secret.encode(),
        f"{timestamp}{nonce}{body}".encode(),
        hashlib.sha256
    ).hexdigest()
    
    if not hmac.compare_digest(signature, expected):
        return False
    
    _cleanup_expired_nonces()
    
    if nonce in NONCE_CACHE:
        return False
    
    NONCE_CACHE[nonce] = now
    if len(NONCE_CACHE) > NONCE_CACHE_SIZE:
        NONCE_CACHE.popitem(last=False)
    
    return True
```

#### 7.1.1 机器码生成规则

```python
def get_machine_id(self) -> str:
    """
    生成机器唯一标识
    
    算法说明:
    1. Windows: CPU ID + 主板序列号 + MAC地址
    2. Linux: CPU ID + 主板序列号 + MAC地址
    3. 最终: SHA256(组件拼接) 前32位
    
    稳定性保证:
    - 正常使用: 机器码稳定不变
    - 重装系统: 机器码不变（依赖硬件）
    - 更换硬件: 可能变化（见迁移流程）
    
    降级策略:
    - wmic 不可用时（Windows 11+ 部分环境）
    - 使用 PowerShell 或注册表替代
    - 最差情况仅用 MAC 地址
    """
    if self._machine_id:
        return self._machine_id
        
    components = []
    
    try:
        if platform.system() == "Windows":
            cpu_id = self._get_windows_cpu_id()
            if cpu_id:
                components.append(f"CPU:{cpu_id}")
            
            board_sn = self._get_windows_board_sn()
            if board_sn:
                components.append(f"BOARD:{board_sn}")
            
        elif platform.system() == "Linux":
            try:
                cpu_info = Path("/proc/cpuinfo").read_text()
                for line in cpu_info.split("\n"):
                    if "Serial" in line or "processor" in line:
                        components.append(line)
                        break
            except Exception:
                pass
            
            try:
                board_info = subprocess.run(
                    ["cat", "/sys/class/dmi/id/board_serial"],
```

```python
from __future__ import annotations

import hashlib
import json

def _encrypt_cache(data: str, key: str) -> str:
    """
    加密缓存数据
    - 算法: AES-256-CBC
    - 密钥: 机器码 SHA256 哈希
    - IV: 随机生成，存储在密文前 16 字节
    
    安全说明:
    - 随机 IV 保证相同数据每次加密结果不同
    - IV 明文存储在密文前，解密时提取
    - 本地加密定位为"防随手查看"，核心安全依赖服务端签名
    """
    try:
        from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
        from cryptography.hazmat.backends import default_backend
        import base64
        import os
        
        key_bytes = hashlib.sha256(key.encode()).digest()
        iv = os.urandom(16)
        
        pad_len = 16 - (len(data) % 16)
        padded_data = data + chr(pad_len) * pad_len
        
        cipher = Cipher(algorithms.AES(key_bytes), modes.CBC(iv), backend=default_backend())
        encryptor = cipher.encryptor()
        encrypted = encryptor.update(padded_data.encode()) + encryptor.finalize()
        
        return base64.b64encode(iv + encrypted).decode()
    except ImportError:
        return data


def _decrypt_cache(encrypted_data: str, key: str) -> str:
    """解密缓存数据"""
    try:
        from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
        from cryptography.hazmat.backends import default_backend
        import base64
        
        key_bytes = hashlib.sha256(key.encode()).digest()
        
        raw = base64.b64decode(encrypted_data.encode())
        iv = raw[:16]
        encrypted = raw[16:]
        
        cipher = Cipher(algorithms.AES(key_bytes), modes.CBC(iv), backend=default_backend())
        decryptor = cipher.decryptor()
        decrypted = decryptor.update(encrypted) + decryptor.finalize()
        
        pad_len = decrypted[-1]
        return decrypted[:-pad_len].decode()
    except ImportError:
        return encrypted_data


@dataclass
class LicenseStatus:
    valid: bool
    license_type: str
    voice_enabled: bool
    deepseek_enabled: bool
    voice_daily_quota: int
    deepseek_monthly_quota: int
    voice_used_today: int
    deepseek_used_this_month: int
    expires_at: datetime | None
    offline_grace_until: datetime | None
    message: str = ""


class LicenseManager:
    """
    授权管理器
    
    职责:
    1. 管理授权码激活/验证
    2. 缓存授权状态 (支持离线)
    3. 获取临时访问 Token
    4. 检查功能权限
    5. 心跳上报
    """
    
    SERVER_URL = "https://your-license-server.com"
    CACHE_FILE = "license_cache.enc"
    OFFLINE_GRACE_DAYS = 7
    HEARTBEAT_INTERVAL_SEC = 1800  # 30分钟（Phase 1 优化：减少服务端压力）
    
    def __init__(self, cache_dir: Path):
        self.cache_dir = cache_dir
        self.cache_file = cache_dir / self.CACHE_FILE
        self._access_token: str | None = None
        self._token_expires_at: datetime | None = None
        self._cached_status: LicenseStatus | None = None
        self._machine_id: str | None = None
        self._heartbeat_enabled = False
        self._load_cache()
    
    def get_machine_id(self) -> str:
        """
        生成机器唯一标识
        
        完整实现见 7.1.1 节，包含：
        - Windows: wmic → PowerShell → 注册表 三级降级
        - Linux: /proc/cpuinfo + DMI
        - MAC 地址兜底
        """
        if self._machine_id:
            return self._machine_id
        
        cpu_id = self._get_windows_cpu_id() if platform.system() == "Windows" else self._get_linux_cpu_id()
        board_sn = self._get_windows_board_sn() if platform.system() == "Windows" else self._get_linux_board_sn()
        mac = hex(uuid.getnode())[2:]
        
        components = []
        if cpu_id:
            components.append(f"CPU:{cpu_id}")
        if board_sn:
            components.append(f"BOARD:{board_sn}")
        components.append(f"MAC:{mac}")
        
        fingerprint = "|".join(components)
        self._machine_id = "SHA256:" + hashlib.sha256(fingerprint.encode()).hexdigest()[:32]
        return self._machine_id
    
    def activate(self, license_code: str, machine_name: str = "") -> LicenseStatus:
        """激活授权码"""
        machine_id = self.get_machine_id()
        
        try:
            response = requests.post(
                f"{self.SERVER_URL}/api/v1/auth/activate",
                json={
                    "license_code": license_code,
                    "machine_id": machine_id,
                    "machine_name": machine_name or platform.node(),
                    "app_version": "1.0.0"
                },
                timeout=10
            )
            
            if response.status_code == 200:
                data = response.json()["data"]
                self._access_token = data["access_token"]
                self._token_expires_at = datetime.utcnow() + timedelta(seconds=data["token_expires_in"])
                
                status = self._parse_license_response(data)
                self._save_cache(status, license_code)
                
                self._start_heartbeat()
                
                return status
            else:
                error = response.json().get("message", "激活失败")
                return self._create_invalid_status(error)
        except requests.RequestException as e:
            return self._create_invalid_status(f"网络错误: {e}")
    
    def deactivate(self) -> tuple[bool, str]:
        """解绑设备"""
        if not self._access_token:
            return False, "未激活"
        
        try:
            response = requests.post(
                f"{self.SERVER_URL}/api/v1/auth/deactivate",
                headers={"Authorization": f"Bearer {self._access_token}"},
                json={"machine_id": self.get_machine_id()},
                timeout=10
            )
            
            if response.status_code == 200:
                self._clear_cache()
                self._access_token = None
                self._token_expires_at = None
                self._cached_status = None
                self._stop_heartbeat()
                return True, "解绑成功"
            else:
                error = response.json().get("message", "解绑失败")
                return False, error
        except requests.RequestException as e:
            return False, f"网络错误: {e}"
    
    def check_status(self, force_online: bool = False) -> LicenseStatus:
        """检查授权状态"""
        if force_online or self._should_refresh_token():
            return self._online_check()
        
        if self._cached_status and self._cached_status.valid:
            if self._is_offline_grace_valid():
                return self._cached_status
        
        return self._online_check()
    
    def can_use_voice(self) -> tuple[bool, str]:
        """检查是否可以使用语音功能"""
        status = self.check_status()
        if not status.valid:
            return False, status.message
        if not status.voice_enabled:
            return False, "当前授权未启用语音功能"
        if status.voice_daily_quota > 0 and status.voice_used_today >= status.voice_daily_quota:
            return False, "今日语音配额已用尽"
        return True, ""
    
    def can_use_deepseek(self) -> tuple[bool, str]:
        """检查是否可以使用 DeepSeek"""
        status = self.check_status()
        if not status.valid:
            return False, status.message
        if not status.deepseek_enabled:
            return False, "当前授权未启用 DeepSeek 功能"
        if status.deepseek_monthly_quota > 0 and status.deepseek_used_this_month >= status.deepseek_monthly_quota:
            return False, "本月 DeepSeek 配额已用尽"
        return True, ""
    
    def get_access_token(self) -> str | None:
        """获取有效的访问 Token"""
        if self._access_token and self._token_expires_at:
            if datetime.utcnow() < self._token_expires_at:
                return self._access_token
        
        self._online_check()
        return self._access_token
    
    def _start_heartbeat(self):
        """启动心跳线程"""
        import threading
        
        self._heartbeat_enabled = True
        
        def heartbeat_loop():
            while self._heartbeat_enabled:
                try:
                    self._send_heartbeat()
                except Exception:
                    pass
                
                import time
                for _ in range(self.HEARTBEAT_INTERVAL_SEC):
                    if not self._heartbeat_enabled:
                        break
                    time.sleep(1)
        
        thread = threading.Thread(target=heartbeat_loop, daemon=True)
        thread.start()
    
    def _stop_heartbeat(self):
        """停止心跳"""
        self._heartbeat_enabled = False
    
    def _send_heartbeat(self):
        """发送心跳"""
        if not self._access_token:
            return
        
        try:
            response = requests.post(
                f"{self.SERVER_URL}/api/v1/auth/heartbeat",
                headers={"Authorization": f"Bearer {self._access_token}"},
                json={
                    "machine_id": self.get_machine_id(),
                    "app_version": "1.0.0"
                },
                timeout=5
            )
            
            if response.status_code == 200:
                data = response.json()["data"]
                if data.get("quota"):
                    if self._cached_status:
                        self._cached_status.voice_used_today = data["quota"].get("voice_used_today", 0)
                        self._cached_status.deepseek_used_this_month = data["quota"].get("deepseek_used_this_month", 0)
        except requests.RequestException:
            pass
    
    def _should_refresh_token(self) -> bool:
        if not self._access_token or not self._token_expires_at:
            return True
        return datetime.utcnow() > self._token_expires_at - timedelta(hours=1)
    
    def _is_offline_grace_valid(self) -> bool:
        if not self._cached_status or not self._cached_status.offline_grace_until:
            return False
        return datetime.utcnow() < self._cached_status.offline_grace_until
    
    def _online_check(self) -> LicenseStatus:
        """在线验证"""
        if not self._access_token:
            cached = self._load_cache()
            if cached:
                return cached
            return self._create_invalid_status("未激活")
        
        try:
            response = requests.get(
                f"{self.SERVER_URL}/api/v1/auth/status",
                headers={"Authorization": f"Bearer {self._access_token}"},
                timeout=10
            )
            
            if response.status_code == 200:
                data = response.json()["data"]
                status = self._parse_license_response(data)
                self._cached_status = status
                self._save_cache(status)
                return status
            else:
                return self._create_invalid_status("授权验证失败")
        except requests.RequestException:
            if self._cached_status and self._is_offline_grace_valid():
                return self._cached_status
            return self._create_invalid_status("网络不可用")
    
    def _save_cache(self, status: LicenseStatus, license_code: str = ""):
        cache_data = {
            "status": {
                "valid": status.valid,
                "license_type": status.license_type,
                "voice_enabled": status.voice_enabled,
                "deepseek_enabled": status.deepseek_enabled,
                "voice_daily_quota": status.voice_daily_quota,
                "deepseek_monthly_quota": status.deepseek_monthly_quota,
                "voice_used_today": status.voice_used_today,
                "deepseek_used_this_month": status.deepseek_used_this_month,
                "expires_at": status.expires_at.isoformat() if status.expires_at else None,
                "offline_grace_until": (datetime.utcnow() + timedelta(days=self.OFFLINE_GRACE_DAYS)).isoformat(),
            },
            "license_code": license_code,
            "cached_at": datetime.utcnow().isoformat(),
            "machine_id": self.get_machine_id()
        }
        
        json_data = json.dumps(cache_data, ensure_ascii=False, indent=2)
        encrypted = _encrypt_cache(json_data, self.get_machine_id())
        self.cache_file.write_text(encrypted, encoding="utf-8")
    
    def _load_cache(self) -> LicenseStatus | None:
        if not self.cache_file.exists():
            return None
        try:
            encrypted = self.cache_file.read_text(encoding="utf-8")
            json_data = _decrypt_cache(encrypted, self.get_machine_id())
            data = json.loads(json_data)
            
            if data.get("machine_id") != self.get_machine_id():
                return None
            
            status_data = data["status"]
            self._cached_status = LicenseStatus(
                valid=status_data["valid"],
                license_type=status_data["license_type"],
                voice_enabled=status_data["voice_enabled"],
                deepseek_enabled=status_data["deepseek_enabled"],
                voice_daily_quota=status_data["voice_daily_quota"],
                deepseek_monthly_quota=status_data["deepseek_monthly_quota"],
                voice_used_today=status_data["voice_used_today"],
                deepseek_used_this_month=status_data["deepseek_used_this_month"],
                expires_at=datetime.fromisoformat(status_data["expires_at"]) if status_data.get("expires_at") else None,
                offline_grace_until=datetime.fromisoformat(status_data["offline_grace_until"]) if status_data.get("offline_grace_until") else None,
            )
            return self._cached_status
        except Exception:
            return None
    
    def _clear_cache(self):
        if self.cache_file.exists():
            self.cache_file.unlink()
    
    def _parse_license_response(self, data: dict) -> LicenseStatus:
        license = data.get("license", {})
        quota = data.get("quota", {})
        return LicenseStatus(
            valid=True,
            license_type=license.get("type", "unknown"),
            voice_enabled=license.get("voice_enabled", False),
            deepseek_enabled=license.get("deepseek_enabled", False),
            voice_daily_quota=license.get("voice_daily_quota", 0),
            deepseek_monthly_quota=license.get("deepseek_monthly_quota", 0),
            voice_used_today=quota.get("voice_used_today", 0),
            deepseek_used_this_month=quota.get("deepseek_used_this_month", 0),
            expires_at=datetime.fromisoformat(license["expires_at"].replace("Z", "+00:00")) if license.get("expires_at") else None,
            offline_grace_until=datetime.utcnow() + timedelta(days=self.OFFLINE_GRACE_DAYS),
        )
    
    def _create_invalid_status(self, message: str) -> LicenseStatus:
        return LicenseStatus(
            valid=False, license_type="none", voice_enabled=False,
            deepseek_enabled=False, voice_daily_quota=0,
            deepseek_monthly_quota=0, voice_used_today=0,
            deepseek_used_this_month=0, expires_at=None,
            offline_grace_until=None, message=message
        )
```

```python
            "max_tokens": 512,
        }
        
        response = requests.post(self.base_url, headers=headers, json=payload, timeout=30)
        response.raise_for_status()
        result = response.json()
        return result["choices"][0]["message"]["content"]
    
    def parse_json(self, prompt: str, model: str | None = None) -> dict[str, Any] | None:
        """生成并解析 JSON 响应"""
        import re
        import json
        
        response = self.generate(prompt, model)
        
        code_block = re.search(r"```(?:json)?\s*\n?(.*?)```", response, re.DOTALL)
        if code_block:
            try:
                return json.loads(code_block.group(1).strip())
            except json.JSONDecodeError:
                pass
        
        depth = 0
        start = None
        for i, ch in enumerate(response):
            if ch == "{":
                if depth == 0:
                    start = i
                depth += 1
            elif ch == "}":
                depth -= 1
                if depth == 0 and start is not None:
                    try:
                        return json.loads(response[start : i + 1])
                    except json.JSONDecodeError:
                        start = None
        return None


def _ensure_env_loaded() -> None:
    """加载 .env 文件"""
    from pathlib import Path
    
    package_root = Path(__file__).resolve().parent
    project_root = package_root.parent
    
    for env_path in (package_root / ".env", project_root / ".env"):
        if not env_path.exists():
            continue
        for line in env_path.read_text(encoding="utf-8").splitlines():
            normalized = line.strip()
            if not normalized or normalized.startswith("#") or "=" not in normalized:
                continue
            key, value = normalized.split("=", 1)
            key = key.strip()
            value = value.strip()
            if key and key not in os.environ:
                os.environ[key] = value
```

## 八、安全策略

### 8.1 客户端安全

- 客户端不保存明文 API Key
- Token 仅存储在内存中，不持久化
- 本地缓存使用 AES-256 加密，密钥为机器码
- 离线宽限期限制为 7 天

### 8.2 通信安全

- 全程 HTTPS 加密
- Token 有时效（默认 24 小时）
- 敏感操作需要重新验证

### 8.3 后台安全

- API Key 存储在环境变量或密钥管理服务
- Token 使用 JWT 签名
- 所有操作记录审计日志
- 支持远程吊销授权

### 8.4 缓存安全机制（服务端签名）

**核心问题：** 本地缓存即使加密，用户仍可在同一台机器上解密并篡改过期时间。

**解决方案：** 服务端对缓存内容签名，关键字段放入签名 payload。

#### 8.4.1 服务端签发缓存凭证

```python
import jwt
from datetime import datetime, timedelta

CACHE_SIGNING_SECRET = "your-cache-signing-secret"

def create_cache_token(license_info: dict, machine_id: str) -> str:
    """
    服务端签发缓存凭证
    
    签名内容包括:
    - license_id: 授权ID
    - machine_id: 机器码绑定
    - expires_at: 授权到期时间
    - offline_until: 离线宽限截止时间
    - quota_snapshot: 配额快照
    """
    offline_until = datetime.utcnow() + timedelta(days=7)
    
    payload = {
        "license_id": license_info["id"],
        "machine_id": machine_id,
        "license_type": license_info["license_type"],
        "voice_enabled": license_info["voice_enabled"],
        "deepseek_enabled": license_info["deepseek_enabled"],
        "expires_at": license_info["expires_at"],
        "offline_until": offline_until.isoformat(),
        "quota": license_info.get("quota", {}),
        "iat": datetime.utcnow(),
    }
    
    return jwt.encode(payload, CACHE_SIGNING_SECRET, algorithm="HS256")


def verify_cache_token(token: str, machine_id: str) -> dict | None:
    """
    验证缓存凭证
    
    返回: 验证成功返回 payload，失败返回 None
    """
    try:
        payload = jwt.decode(token, CACHE_SIGNING_SECRET, algorithms=["HS256"])
        
        if payload.get("machine_id") != machine_id:
            return None
        
        offline_until = datetime.fromisoformat(payload["offline_until"])
        if datetime.utcnow() > offline_until:
            return None
        
        return payload
    except jwt.InvalidTokenError:
        return None
```

#### 8.4.4 安全特性总结

| 攻击场景 | 防护措施 |
|----------|----------|
| 复制缓存到其他机器 | machine_id 绑定验证失败 |
| 修改过期时间 | 服务端签名验证失败 |
| 重放旧缓存 | offline_until 时间检查 |
| 解密查看内容 | AES-256 加密（虽可解密但无法篡改签名） |

### 8.5 缓存安全定位说明

**重要：本地加密的安全边界**

| 安全层级 | 机制 | 防护目标 | 强度 |
|----------|------|----------|------|
| 第一层 | AES-256-CBC 加密 | 防随手查看 | 中 |
| 第二层 | 服务端 JWT 签名 | 防篡改 | 高 |
| 第三层 | machine_id 绑定 | 防复制到其他机器 | 高 |
| 第四层 | offline_until 时效 | 防重放旧缓存 | 高 |

**核心安全依赖服务端签名**，本地加密定位为"防随手查看"，不依赖其作为核心安全边界。

```python
class Phase1StateManager:
    """
    Phase 1 状态管理（单机内存 + 数据库）
    
    适用场景：
    - 单实例部署
    - 设备数量 10-50 台
    - QPS < 100
    
    不适用：
    - 多实例部署（状态不一致）
    - 高并发场景（内存压力）
    """
    
    def __init__(self):
        self._rate_limits = defaultdict(list)
        self._nonces = OrderedDict()
        self._nonce_max_size = 10000
        self._nonce_expire_seconds = 300
    
    def check_rate_limit(self, key: str, max_req: int, window: int) -> bool:
        now = time.time()
        requests = self._rate_limits[key]
        requests[:] = [t for t in requests if now - t < window]
        if len(requests) >= max_req:
            return False
        requests.append(now)
        return True
    
    def _cleanup_expired_nonces(self):
        """清理过期的 nonce（与 6.3.3 节 verify_request_signature 对齐）"""
        now = time.time()
        expired_keys = [
            nonce for nonce, ts in self._nonces.items()
            if now - ts > self._nonce_expire_seconds
        ]
        for key in expired_keys:
            del self._nonces[key]
    
    def check_nonce(self, nonce: str) -> bool:
        self._cleanup_expired_nonces()
        if nonce in self._nonces:
            return False
        self._nonces[nonce] = time.time()
        if len(self._nonces) > self._nonce_max_size:
            self._nonces.popitem(last=False)
        return True
```

**Phase 2 升级路径：**

```python
class Phase2StateManager:
    """
    Phase 2 状态管理（Redis）
    
    适用场景：
    - 多实例部署
    - 高并发场景
    - 需要状态持久化
    """
    
    def __init__(self, redis_client):
        self.redis = redis_client
    
    def check_rate_limit(self, key: str, max_req: int, window: int) -> bool:
        current = self.redis.incr(f"rate:{key}")
        if current == 1:
            self.redis.expire(f"rate:{key}", window)
        return current <= max_req
    
    def check_nonce(self, nonce: str) -> bool:
        """
        检查 nonce 是否已使用（原子操作）
        
        Redis 命令: SET key value NX EX 300
        - NX: 仅当 key 不存在时设置
        - EX 300: 300 秒后过期
        """
        return self.redis.set(f"nonce:{nonce}", "1", nx=True, ex=300)
```

```python
from fastapi import HTTPException, Depends

def require_permission(resource: str, action: str):
    """权限检查装饰器"""
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, admin = Depends(get_current_admin), **kwargs):
            if not has_permission(admin.role_id, resource, action):
                raise HTTPException(
                    403, 
                    f"无权限执行此操作: {resource}.{action}"
                )
            return await func(*args, admin=admin, **kwargs)
        return wrapper
    return decorator
```

### 12.8 管理员账户创建脚本

```python
# scripts/create_admin.py
from getpass import getpass
from app.database import SessionLocal
from app.models import Admin
from passlib.hash import bcrypt

def main():
    print("=== 创建管理员账户 ===")
    username = input("管理员用户名: ").strip()
    if not username:
        print("用户名不能为空")
        return
    
    password = getpass("密码: ")
    if len(password) < 6:
        print("密码至少6位")
        return
    
    confirm = getpass("确认密码: ")
    if password != confirm:
        print("两次密码不一致")
        return
    
    role = input("角色 (super_admin/admin/operator) [admin]: ").strip() or "admin"
    if role not in ("super_admin", "admin", "operator"):
        print("无效角色")
        return
    
    db = SessionLocal()
    try:
        existing = db.query(Admin).filter(Admin.username == username).first()
        if existing:
            print(f"用户名 {username} 已存在")
            return
        
        admin = Admin(
            username=username,
            password_hash=bcrypt.hash(password),
            role=role
        )
        db.add(admin)
        db.commit()
        print(f"✓ 管理员 {username} 创建成功，角色: {role}")
    except Exception as e:
        db.rollback()
        print(f"✗ 创建失败: {e}")
    finally:
        db.close()

if __name__ == "__main__":
    main()
```
