# 机械手自然语言编程控制系统 — 使用手册

## 快速开始

### 第一步：连接控制器

1. 在顶部输入控制器的 **IP 地址**（默认 `192.168.1.11`）
2. 选择控制器类型：
   - **真实控制器**：连接实际设备
   - **模拟控制器**：用于学习和测试，不需要真实设备
3. 点击 **检测连接**
4. 连接成功后，右侧状态灯变为 **绿色"空闲"**

> 连接成功后，系统会自动每 0.5 秒读取一次机械手状态，界面实时更新。

---

### 第二步：执行指令

系统提供三种操作方式，根据需要选择：

| 方式 | 适合场景 |
|------|----------|
| 单次执行 | 执行一条指令 |
| 流程执行 | 按顺序自动执行多条指令 |
| 自然语言 | 用中文或语音控制 |

---

## 单次执行

点击 **"单次执行"** 标签页。

界面会显示所有可用指令的卡片，每张卡片显示指令名称和简要信息。

**操作方法：**

1. 如果指令较多，可以在顶部 **筛选框** 输入关键词搜索
2. 也可以用 **类型下拉框** 筛选：只看"参数型"或"固定型"
3. 找到目标指令，点击卡片上的 **"执行"** 按钮
4. 观察底部状态面板确认执行结果

**什么是参数型和固定型？**

- **参数型**：带有坐标参数（位置、角度、速度），卡片上会显示坐标预览
- **固定型**：无需参数，点击直接执行，如归零、夹爪动作等

---

## 流程执行

点击 **"流程执行"** 标签页。

流程是把多条指令按顺序编排好，一键自动依次执行。

**操作方法：**

1. 从 **流程下拉框** 选择一个已编排好的流程
2. 点击 **"开始流程"**，系统自动依次执行每一步
3. 也可以点击 **"单步执行"**，每点一次只执行一步，方便调试

**流程控制按钮：**

| 按钮 | 作用 |
|------|------|
| 开始流程 | 自动执行全部步骤 |
| 单步执行 | 只执行当前一步 |
| 停止流程 | 中途停止 |
| 重置流程 | 回到第一步重新开始 |

**步骤状态说明：**

- **待执行**：还没轮到这一步
- **执行中**：正在执行（蓝色高亮）
- **已完成**：执行成功
- **失败**：执行出错，流程自动停止
- **已停止**：被手动停止

---

## 自然语言控制

点击 **"自然语言执行"** 标签页。

这是最直观的操作方式，直接用中文描述你想做什么。

### 文字输入

在文本框中输入指令，然后点 **"执行"**。如果只想预览解析结果而不执行，点 **"解析文本"**。

**支持的指令示例：**

| 你说什么 | 系统做什么 |
|----------|-----------|
| 回零 | 回到零点位置 |
| 把机械手移动到位置A | 移动到位置A |
| 抓一下 | 夹爪闭合 |
| 松开 | 夹爪松开 |
| 启动 | 启动自动运行 |
| 急停 | 紧急停止 |
| 执行流程11 | 启动名为"11"的流程 |
| 先归零再移动到位置A | 依次执行：归零 → 位置A |

### 语音输入

1. 从 **麦克风下拉框** 选择录音设备（如果看不到设备，点 **"刷新设备"**）
2. 点击 **"开始录音"**，对着麦克风说话
3. 说完后点击 **"停止录音"**
4. 系统自动识别语音并填入文本框
5. 点击 **"执行"**

> 语音识别使用讯飞服务，需要提前配置 API 凭证。勾选 **"使用DeepSeek"** 可以提高复杂指令的识别准确率。

---

## 右侧系统按钮

右侧面板提供 6 个系统控制按钮，用于控制机械手的整体运行状态：

| 按钮 | 什么时候用 |
|------|-----------|
| **上电** | 系统刚启动时，给控制器上电 |
| **启动**（绿色） | 开始自动运行模式 |
| **停机** | 正常停止运行 |
| **暂停**（黄色） | 临时暂停当前任务 |
| **继续** | 恢复暂停的任务 |
| **急停**（红色） | 紧急情况立即使用！ |

> **注意**：流程执行期间，系统按钮会自动禁用。需要先停止流程才能操作系统按钮。

### 状态指示灯

右侧面板底部的状态灯显示系统当前状态：

| 颜色 | 状态 | 含义 |
|------|------|------|
| 绿色 | 空闲 | 已连接，没有任务在跑 |
| 蓝色 | 运行中 | 正在执行指令 |
| 黄色 | 暂停 | 任务已暂停 |
| 红色 | 异常 | 报警或通讯故障 |
| 灰色 | 离线 | 未连接控制器 |

---

## 底部状态面板

界面底部有三个信息面板，实时显示系统状态：

### 机械手状态

显示机械手当前的空间坐标（X/Y/Z）、旋转角度（RX/RY/RZ）、速度、夹爪状态、伺服状态等。

### 执行摘要

显示当前模式（自动/调试）、忙闲状态、执行结果、报警信息等。

### 最近执行记录

显示最近执行的指令列表，包括任务编号、指令名称和执行结果。

---

## 后台管理页面

点击左侧 **"后台"** 导航按钮进入。这个页面用于管理指令模板和系统配置，通常由工程师使用。

### 管理指令模板

1. 左侧列表选择一个模板，中间区域自动加载该模板的参数
2. 修改参数后点 **"保存"**
3. 点 **"新增"** 创建空白模板
4. 点 **"另存为"** 以副本形式保存
5. 点 **"删除"** 删除当前模板
6. 点 **"导出指令"** / **"导入指令"** 进行批量操作

### 管理流程

在后台页面点击 **"流程管理"** 标签页：

1. 点 **"新增流程"**，输入流程名称
2. 从右侧 **"可选模板"** 列表中选择需要的指令
3. 点 **"添加步骤"** 将指令加入流程
4. 用 **"上移"** / **"下移"** 调整执行顺序
5. 点 **"保存流程"**

### 系统参数设置

在 **"系统参数"** 标签页中设置 X/Y/Z 三个轴的运动范围限制。设置后，如果指令的目标坐标超出范围，系统会拒绝执行并提示。

### 安全规避设置

在 **"安全中间点"** 标签页中配置防碰撞策略：

- **关闭**：不做任何规避
- **自动判断**：系统根据姿态变化自动判断是否需要经过安全中间点
- **每次都经过中间点**：所有运动指令都先经过安全中间点

---

## 日志页面

点击左侧 **"日志"** 导航按钮进入。

- **刷新日志**：刷新显示
- **导出日志**：保存为文件
- **清空日志**：清除所有记录

日志最多保留 200 条，关闭程序后日志不会保存。如有需要请及时导出。

---

## 常见操作速查

### 日常操作

| 我想... | 操作 |
|---------|------|
| 连接机械手 | 输入IP → 检测连接 |
| 移动到某个位置 | 单次执行 → 找到指令 → 点执行 |
| 跑一个流程 | 流程执行 → 选流程 → 开始流程 |
| 用说话控制 | 自然语言 → 开始录音 → 说话 → 停止录音 → 执行 |
| 用打字控制 | 自然语言 → 输入文字 → 执行 |

### 异常处理

| 情况 | 处理方法 |
|------|---------|
| 急停 | 直接点右侧红色 **"急停"** 按钮 |
| 急停后恢复 | 先点 **"上电"**，再正常操作 |
| 连接断开 | 检查网线/IP，重新点 **"检测连接"** |
| 坐标超出范围 | 去后台 → 系统参数，调整轴范围 |
| 流程执行失败 | 查看日志页面了解失败原因 |

---

## 注意事项

1. 急停后必须先 **"上电"** 才能恢复操作
2. 流程运行期间不能点系统按钮，需要先停止流程
3. 如果指令的目标坐标超出系统设定的范围，执行会被拒绝
4. 语音和 DeepSeek 功能需要配置 API 密钥，联系工程师获取
5. 日志最多 200 条，关闭程序后消失，重要日志请及时导出
