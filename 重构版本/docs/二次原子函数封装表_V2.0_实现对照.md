# 二次原子函数封装表 V2.0 实现对照

更新时间：2026-05-22

## 当前结论

Qt 离线侧已完成第一版“自然语言 -> 原子解析 -> QueryRecord -> 现有执行链”的最小闭环。当前实现不依赖 Web API，也不要求新增 query_table 固定模板。

可审计清单见：[二次原子函数能力审计清单.md](二次原子函数能力审计清单.md)。

验收口径和剩余项见：[二次原子函数封装表_V2.0_验收口径与剩余项.md](二次原子函数封装表_V2.0_验收口径与剩余项.md)。

真机前逐项检查见：[二次原子函数封装表_V2.0_真机前联调清单.md](二次原子函数封装表_V2.0_真机前联调清单.md)。

## 已实现

| 文档能力 | 当前实现 | 状态 |
|---|---|---|
| 唤醒词隔离 | `VoiceNlpAdapter` 保持“小正/小郑/校正”门禁 | 已实现 |
| 原子记忆参数 | `AtomicMemory`：速度、毫米步长、角度步长、加速度、减速度、确认模式 | 已实现 |
| J 类关节命令 | `J1转到45度`、`J1正转3度` 等解析为 Func106 | 基础实现 |
| V 类虚拟轴命令 | 前进/后退/左移/右移/上升/下降/RX/RY/RZ 正反转解析为 Func107 | 基础实现 |
| C 类笛卡尔命令 | `X/Y/Z/RX/RY/RZ` 显式坐标解析为 Func108 | 基础实现 |
| D 类延时命令 | `等待2秒` 解析为 Func110 | 已实现 |
| IO 类命令 | `IO1开/关` 解析为 Func120 | 已实现 |
| SP 参数命令 | `速度60%`、`加速`、`减速`、`步长10毫米`、`步长5度` | 基础实现 |
| 位置库持久化 | `data/atomic_state.json` 保存速度、步长、确认模式、位置库和位置栈 | 已实现 |
| Q 类看板查询 | `当前位置`、`J1角度`、`各轴角度`、`设备状态`、`有没有报警`、`速度多少`、`通讯正常吗`、`能不能到...` 本地回答 | 基础实现 |
| Q08 目标点可达查询 | `能不能到 350 200 500` 会解析目标 XYZ，并基于当前 X/Y/Z 软限位和执行条件给出离线结论 | 基础实现 |
| 多原子组合命令 | `上升3毫米然后IO1开`、`J1转到45度然后等待2秒然后IO1关` 顺序解析和执行 | 基础实现 |
| 复杂组合保护 | `重复3次`、`同时...并且...`、`如果...就...` 等循环/并行/条件命令会明确拒绝，不进入执行链 | 基础实现 |
| Func11 连续插补保护 | `连续路径`、`插补`、`轨迹`、`Func11` 类命令会明确拒绝，不误拆成普通动作 | 基础实现 |
| 确认模式策略 | 新手模式全部确认；熟练/专家模式低中风险自动执行，高风险运动仍确认 | 已实现 |
| 原子风险分级 | 延时 low、IO medium；虚拟轴按速度/步长/旋转轴细分 low/medium/high；绝对位姿和高速动作 high | 基础实现 |
| 风险可见化与归档 | 用户确认页展示原子风险等级/原因；交互归档 `nlp_result` 顶层写入 `risk_level/risk_reason` | 已实现 |
| NLP 接入 | `atomic_template` 和 `memory` 动作接入 `VoiceNlpPlan` | 已实现 |
| Qt 执行链接入 | `atomic_template` 可复用预检、确认、执行链 | 已实现 |
| 类型 A 归档 | `command_intent_from_plan()` 支持原子模板动态参数 | 已实现 |
| 能力审计清单 | `atomic_capabilities.py` 导出支持项、保护项、延期项，并生成 Markdown 审计表 | 已实现 |
| GUI 能力查询 | 用户页可直接问“现在支持哪些原子命令”，快路径和 NLP 查询层均返回已实现、保护性拒绝和延期项摘要 | 已实现 |

## 尚未完成

| 文档能力 | 缺口 |
|---|---|
| 位置库 | 已实现“保存当前位置为位置A / 删除位置A / 位置A坐标是多少 / 移动到位置A”和 JSON 持久化；位置来源依赖 Qt 当前反馈 |
| 动作历史 | 已实现“继续前进 / 返回 / 再走一次”基础版；返回依赖位置栈，位置栈填充策略仍需结合真实执行结果细化 |
| Q08 动作可达查询 | 已能解析目标 XYZ 并执行离线软限位判断；还不是调用真机 FRAME_TRANS2 的完整 L2 逆解结论 |
| 复杂组合命令 | 已支持基础顺序组合；复杂条件组合、循环、并行组合已做保护性拒绝，但尚未实现真正的条件/循环/并行执行 |
| 风险确认分级策略 | 已按 Func、轴类型、速度、步长做基础分级；后续可结合现场设备能力继续调整阈值 |
| Func11 连续插补 | 已做保护性识别和拒绝；真实连续插补执行仍按 V2.0 建议保留，不在本轮实现 |
| 真机参数边界 | 当前为离线解析和 QueryRecord 生成，未做真实控制器联调 |
