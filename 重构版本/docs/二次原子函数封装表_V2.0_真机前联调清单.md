# 二次原子函数封装表 V2.0 真机前联调清单

更新时间：2026-05-22

## 目标

本清单只验收“自然语言二次原子层”到 Qt GUI 的现场表现：

1. 用户说或输入什么。
2. GUI 是否识别到正确原子动作。
3. 是否进入正确的预检/确认/拒绝/查询路径。
4. 真机执行时状态、回显、日志是否能闭环。

底层 Func 地址、并行互斥和反馈位请同时参考：

- [最终接口设计/V4.3_真实控制器联调执行清单.md](最终接口设计/V4.3_真实控制器联调执行清单.md)

## 完成判定

本清单可判定通过，当且仅当：

1. A01~F07 在 Qt GUI 中表现符合预期。
2. C01~C07、D03、D06、G01~G06 至少在低速安全工况下完成一轮真机记录。
3. 所有失败项均有日志、截图或现场记录，并已归类为代码问题、配置问题、控制器协议问题或工艺限制。
4. Func11 真执行未开放前，所有轨迹/插补类自然语言必须继续保护性拒绝。
