# 当前实现与编程手册 V1.1 需求对照（非 Web）

日期：2026-05-23；2026-05-25 更新

范围：只对照 Qt 桌面上位机、语音/NLP、协议执行、安全预检、看板、流程、位置、权限、日志、报警等内容。忽略文档目录结构、示例伪代码和 Web 相关实现。

结论：当前实现覆盖了手册中的核心执行链路、Func 范围、5 级语义、唤醒词、7 类看板、L1/L2/L3 预检、回执/确认、流程执行、日志归档等主要能力；但协议基线已从手册 V4.3 演进为 V5.0，位置库/流程库/权限/报警/方言归一化等要求没有完全按手册内容落地。

## 状态说明

| 状态 | 含义 |
|---|---|
| 已实现 | 当前非 Web 主链路已有可运行实现，并有较明确的测试或代码路径。 |
| 部分实现 | 当前已有相近能力，但语义、覆盖范围、强制点或完备性未达到手册要求。 |
| 未实现 | 当前代码未发现对应功能，或只存在文档/测试想法，未进入主实现链路。 |
| 需重定基线 | 手册要求基于 V4.3，但当前主链路已按 V5.0 实现，应以 V5.0 重写验收口径。 |
