# 二次原子函数能力审计清单

| 能力 | key | 状态 | 示例 | 实现位置 | 备注 |
|---|---|---|---|---|---|
| 唤醒词隔离 | `wake_word` | implemented | 小正，上升3毫米、小郑，速度60% | VoiceNlpAdapter + AtomicParser | 生产控制类原子命令必须带唤醒词；单独急停词只提示标准编码。 |
| SP 参数命令 | `memory_sp` | implemented | 速度60%、步长10毫米、专家模式 | AtomicMemory + AtomicResolver._resolve_memory | 速度、步长和确认模式会持久化到 data/atomic_state.json。 |
| J 类关节命令 | `joint_j` | basic | J1转到45度、J2正转3度 | AtomicParser._parse_joint -> Func106 | 绝对关节目标保持高风险确认。 |
| V 类虚拟轴命令 | `virtual_v` | basic | 上升3毫米、左移5毫米、RY正转2度 | AtomicParser._parse_virtual -> Func107 | 按速度、步长、旋转轴做 low/medium/high 基础分级。 |
| C 类笛卡尔命令 | `cartesian_c` | basic | X100Y200Z300、X100Y200Z300RX0RY90RZ0 | AtomicParser._parse_cartesian -> Func108 | 只支持显式坐标，不做自然语言复杂位姿推理。 |
| D 类延时命令 | `delay_d` | implemented | 等待2秒、延时500毫秒 | AtomicParser._parse_delay -> Func110 | 延时动作风险等级为 low。 |
| IO 类命令 | `io` | implemented | IO1开、输出2关闭 | AtomicParser._parse_io -> Func120 | IO 会改变外部设备状态，风险等级为 medium。 |
| 位置库 | `position_library` | basic | 保存当前位置为位置A、移动到位置A、位置A坐标是多少 | AtomicMemory position store | 位置来源依赖 Qt 当前反馈；移动到命名位置生成 Func108。 |
| 动作历史 | `history` | basic | 再走一次、返回上一步、继续上升3毫米 | AtomicMemory last_record / position_stack | 返回依赖位置栈，位置栈填充仍需结合真实执行结果细化。 |
| Q 类看板查询 | `dashboard_q` | basic | 当前位置、速度多少、能不能到350 200 500 | DashboardQueryService | Q08 目标点查询做离线 XYZ 软限位判断，不代表真机 L2 逆解。 |
| 顺序组合命令 | `sequence` | basic | 上升3毫米然后IO1开、J1转到45度然后等待2秒然后IO1关 | VoiceNlpAdapter._split_atomic_parts | 只支持 then-style 顺序组合，整体进入预检/确认链。 |
| 复杂组合保护 | `complex_guard` | guarded | 重复3次、同时上升并IO1开、如果没有报警就上升 | VoiceNlpAdapter._unsupported_complex_atomic_reason | 循环、并行、条件命令保护性拒绝，不进入执行链。 |
| Func11 连续插补保护 | `func11_guard` | guarded | 连续路径经过位置A和位置B、插补到X100Y200Z300、执行轨迹A | VoiceNlpAdapter._unsupported_complex_atomic_reason | 连续插补/轨迹类命令保护性拒绝，避免误拆成普通动作。 |
| Func11 连续插补执行 | `func11_execution` | deferred | 连续路径、轨迹执行 | 未接入 | 真实连续插补执行需要真机协议和路径安全验证，本轮不实现。 |
| 真机参数边界验证 | `machine_validation` | deferred | 真实控制器回显、FRAME_TRANS2、运动完成验证 | 未接入 | 当前为 Qt 离线解析和 QueryRecord 生成，未做真机联调。 |

汇总：共 15 项，已实现 4 项，基础实现 7 项，保护性拒绝 2 项，延期 2 项。
