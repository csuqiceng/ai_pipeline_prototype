# 最终标准协议寄存器通信示意图

## 1. 总体流程

```text
┌──────────────────────────────────────────────────────────────┐
│                         上位机 Qt                           │
│  自然语言/按钮/后台模板                                      │
│  生成标准命令 JSON                                           │
└──────────────────────────────────────────────────────────────┘
                              │
                              │ 组包
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                    指令区 VR[0] ~ VR[15]                    │
├────────┬───────────────┬─────────────────────────────────────┤
│ VR[0]  │ CMD_CODE      │ 命令码                              │
│ VR[1]  │ TASK_ID       │ 任务号                              │
│ VR[2]  │ POS_X         │ X                                   │
│ VR[3]  │ POS_Y         │ Y                                   │
│ VR[4]  │ POS_Z         │ Z                                   │
│ VR[5]  │ ROT_RX        │ RX                                  │
│ VR[6]  │ ROT_RY        │ RY                                  │
│ VR[7]  │ ROT_RZ        │ RZ                                  │
│ VR[8]  │ SPD_PCT       │ 速度百分比                          │
│ VR[9]  │ ACC_PCT       │ 加速度百分比                        │
│ VR[10] │ DEV_ID        │ 设备/工位ID                         │
│ VR[11] │ IO_GRIP       │ 夹爪动作                            │
│ VR[12] │ IO_DOOR       │ 门动作                              │
│ VR[13] │ EXT_P1        │ 扩展参数1                           │
│ VR[14] │ EXT_P2        │ 扩展参数2                           │
│ VR[15] │ SAFETY_LV     │ 安全等级                            │
└────────┴───────────────┴─────────────────────────────────────┘
                              │
                              │ 写入寄存器
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                         下位机控制器                         │
│  读取 VR[0]~VR[15]                                            │
│  解析命令码 + 参数                                             │
│  执行动作：MOVE / IO / WAIT / RESET 等                         │
│  执行中做范围校验 / 安全校验 / 报警处理                         │
└──────────────────────────────────────────────────────────────┘
                              │
                              │ 回写状态
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                    状态区 VR[16] ~ VR[25]                   │
├────────┬───────────────┬─────────────────────────────────────┤
│ VR[16] │ RESULT        │ 执行结果                            │
│ VR[17] │ STATUS        │ 忙闲状态                            │
│ VR[18] │ CUR_X         │ 当前X                               │
│ VR[19] │ CUR_Y         │ 当前Y                               │
│ VR[20] │ CUR_Z         │ 当前Z                               │
│ VR[21] │ CUR_RX        │ 当前RX                              │
│ VR[22] │ CUR_RY        │ 当前RY                              │
│ VR[23] │ CUR_RZ        │ 当前RZ                              │
│ VR[24] │ ALM_CODE      │ 报警码                              │
│ VR[25] │ IO_STAT       │ IO状态位                            │
└────────┴───────────────┴─────────────────────────────────────┘
                              │
                              │ 读取反馈
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                         上位机 Qt                           │
│  更新：执行结果 / 忙闲状态 / 当前坐标 / 报警 / IO状态         │
│  写入日志 / 刷新页面显示                                       │
└──────────────────────────────────────────────────────────────┘
```

## 3. 说明

- 上位机负责把命令组织成固定字段，写入 `VR[0]~VR[15]`
- 下位机负责解析指令区，执行动作，并回写 `VR[16]~VR[25]`
- 上位机再读取状态区，用于页面显示、日志记录和报警提示
- 当前 Qt 项目中：
  - 最终标准协议已经支持这套组包和状态解析
  - 模拟控制器已经支持这套本地闭环验证
  - 真实下位机最终是否完全按此协议运行，还需现场联调确认
