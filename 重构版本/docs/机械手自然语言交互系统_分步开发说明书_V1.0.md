## 第一章：分步开发总原则

### 1.1 为什么必须分步开发

本系统涉及14个功能模块、8个底层Func、5级语义分层、7类看板、3层预演算，代码量预计8000~12000行。如果整体开发，存在以下问题：

| 问题 | 后果 |
|------|------|
| AI上下文窗口有限，无法一次处理全部代码 | 代码质量下降，遗漏增多 |
| 模块间耦合导致改一处动全身 | 调试困难，bug难定位 |
| 硬件依赖导致无法随时测试 | 开发效率低，等待设备 |
| 接口不统一导致集成时大量返工 | 延期风险高 |

**分步开发的核心价值**：每一步都是一个可运行、可验证的里程碑，上一步通过后才进入下一步。

### 1.2 六条分步原则

**原则一：先接口后实现**

每个模块开发前，先定义它对外提供的接口（输入什么、输出什么、什么格式），再写内部实现。接口一旦定义，后续模块就可以基于接口开发，不需要等实现完成。

```
正确做法：先定义 NlpResult dataclass → M3和M4可以并行开发
错误做法：先写M3实现 → M4等M3写完才知道输出格式
```

**原则二：先纯逻辑后硬件依赖**

纯逻辑模块（NLP解析、Func映射、数据管理）不依赖任何硬件，可以在任何电脑上开发测试。硬件依赖模块（MODBUS通讯、语音识别）需要设备才能测试。优先开发纯逻辑模块，确保核心逻辑正确后再接入硬件。

```
开发顺序：M3(NLP) → M4(Func映射) → M1(MODBUS)
测试顺序：纯文本测试 → Mock测试 → 真实设备测试
```

**原则三：每步必须可独立验证**

每一步完成后，必须能独立运行测试，不需要等待其他步骤。验证方式分三级：

| 验证级别 | 方式 | 适用场景 |
|---------|------|---------|
| L1-纯函数测试 | 输入→输出断言 | M3/M4/M9/M8c |
| L2-Mock测试 | 用模拟对象替代硬件 | M2/M5/M6/M11 |
| L3-真实测试 | 连接真实设备 | M1/M7a/M7b |

**原则四：Mock对象与真实对象接口一致**

当依赖模块未开发时，使用Mock对象替代。Mock对象必须实现与真实对象相同的接口，这样后续替换时不需要修改调用方代码。

```python
# Mock和真实对象接口一致，替换时只改一行
# writer = MockModbusWriter()    # 开发时用Mock
writer = ModbusWriter()          # 集成时换真实
```

**原则五：每步产出可运行的代码**

每一步完成后，不是产出"半成品"，而是产出"可运行的最小可用系统"。即使功能不完整，但已有功能必须能正确运行。

```
阶段0完成：能加载配置、组装JSON报文、记忆参数正确
阶段1完成：能解析"小正，上升3毫米"并输出Func107参数
阶段2完成：能管理位置库和流程库
阶段3完成：能控制机械手运动
```

**原则六：接口变更必须双向通知**

开发过程中如果需要修改已定义的接口，必须通知所有依赖该接口的模块开发者（包括AI），确保同步更新。

### 1.3 分步开发的前提条件

在开始分步开发之前，必须确认以下前提条件已满足：

| 前提条件 | 状态 | 说明 |
|---------|------|------|

### 2.3 段间接口契约

每个阶段完成后，向后续阶段提供的接口（即"契约"）：

| 阶段 | 提供的接口 | 接口文件 | 后续谁用 |
|------|-----------|---------|---------|
| 阶段0 | ConfigManager / JsonMessage / MemoryParams | interfaces.py | 全部模块 |
| 阶段1 | classify_input()→NlpResult / map_to_func()→FuncResult | interfaces.py | M5/M6/M7c |

| 阶段3 | ModbusWriter / StatusPoller / DashboardCache | interfaces.py | M5/M6/M11 |
| 阶段4 | L1Precheck / EmergencyChannel / L2L3Precheck | interfaces.py | M7c/Pipeline |
| 阶段5 | Pipeline（完整流水线） | pipeline.py | 主程序 |

### 2.4 段间验证检查点

每个阶段完成时，必须通过以下检查点才能进入下一阶段：

| 检查点 | 检查内容 | 不通过的后果 |
|--------|---------|------------|
| 接口一致性 | 本阶段产出的接口与interfaces.py定义一致 | 后续模块编译失败 |
| 测试通过率 | 本阶段所有测试用例100%通过 | 隐藏bug在集成时爆发 |
| Mock兼容性 | Mock对象与真实对象接口一致 | 替换时需要改代码 |
| 文档同步 | 接口变更已更新到interfaces.py | 后续开发基于错误接口 |

# config/config_manager.py
import json
import os
from typing import Any

class ConfigManager:
    def __init__(self, config_dir: str):
        self._config_dir = config_dir
        self._configs = {}
        self.reload()

    def reload(self):
        """重新加载所有配置文件"""
        for name in ["system_config", "query_table", "flows", "avoidance_rules"]:
            path = os.path.join(self._config_dir, f"{name}.json")
            if os.path.exists(path):
                with open(path, 'r', encoding='utf-8') as f:
                    self._configs[name] = json.load(f)

    def load_config(self, config_name: str) -> dict:
        return self._configs.get(config_name, {})

    def get(self, key: str, default=None) -> Any:
        """支持点号分隔的嵌套key，如 "echo_retry_count" """
        # 先在system_config中查找
        sys_cfg = self._configs.get("system_config", {})
        if key in sys_cfg:
            return sys_cfg[key]
        return default

import json
import uuid
from datetime import datetime

class JsonMessage:
    @staticmethod
    def build_command(func_id: int, ieee_dict: dict, metadata: dict = None) -> dict:
        return {
            "msg_id": str(uuid.uuid4()),
            "timestamp": datetime.now().isoformat(),
            "input_type": metadata.get("input_type", "text") if metadata else "text",
            "raw_text": metadata.get("raw_text", "") if metadata else "",
            "semantic_level": metadata.get("semantic_level", 3) if metadata else 3,
            "intent": "command",
            "confidence": metadata.get("confidence", 1.0) if metadata else 1.0,
            "params": {
                "func_id": func_id,
                **ieee_dict
            },
            "emergency_code": None
        }

    @staticmethod
    def build_query(query_type: str, params: dict = None) -> dict:
        return {
            "msg_id": str(uuid.uuid4()),
            "timestamp": datetime.now().isoformat(),
            "input_type": "text",
            "raw_text": "",
            "semantic_level": 2,
            "intent": "query",
            "confidence": 1.0,
            "params": params or {},
            "emergency_code": None
        }

    @staticmethod
    def build_feedback(func_id: int, success: bool, detail: str,
                       device_status: dict = None, safety_result: dict = None,
                       progress: dict = None, emergency: dict = None) -> dict:
        msg = {
            "msg_id": str(uuid.uuid4()),
            "timestamp": datetime.now().isoformat(),
            "reply_type": "result",
            "text": detail,
            "confidence": 1.0,
            "device_status": device_status or {},
            "safety_precheck": safety_result or {},
            "func_execution": {
                "func_id": func_id,
                "state": "done" if success else "error",
                "progress_pct": 100 if success else 0
            },
            "progress": progress or {},
            "emergency": emergency or {}
        }
        return msg

    @staticmethod
    def parse_message(json_str: str) -> dict:
        return json.loads(json_str)

        self._state = MemoryState()
        if config:
            # 从配置加载默认值
            self._state.current_speed = config.get("default_speed", 50.0)
            self._state.work_speed = config.get("work_speed", 30.0)

    @property
    def state(self) -> MemoryState:
        return self._state

    def set_speed(self, pct: float):
        self._state.current_speed = max(5.0, min(150.0, pct))

    def speed_up(self, delta: float = 10.0):
        self.set_speed(self._state.current_speed + delta)

    def speed_down(self, delta: float = 10.0):
        self.set_speed(self._state.current_speed - delta)

    def set_step_mm(self, mm: float):
        self._state.current_step_mm = max(1.0, min(500.0, mm))

    def set_step_deg(self, deg: float):
        self._state.current_step_deg = max(0.5, min(90.0, deg))

        if len(self._stack) > self._max_depth:
            self._stack.pop(0)
        self._last_command = {"func_id": func_id, "params": params.copy()}

    def pop(self) -> Optional[tuple]:
        if self._stack:
            return self._stack.pop()["position"]
        return None

    def record_direction(self, from_pos: tuple, to_pos: tuple):
        """记录运动方向，用于"继续前进" """
        dx = to_pos[0] - from_pos[0]
        dy = to_pos[1] - from_pos[1]
        dz = to_pos[2] - from_pos[2]
        d = (dx**2 + dy**2 + dz**2) ** 0.5
        if d > 0.001:
            self._last_direction = (dx/d, dy/d, dz/d)
            self._last_step = d

    def get_last_direction(self) -> Optional[tuple]:
        return self._last_direction

    def get_last_command(self) -> Optional[dict]:
        return self._last_command
```

# nlp/classify_input.py
import re

def classify_input(text: str, memory: MemoryParams = None) -> NlpResult:
    """NLP解析主入口"""

    # 步骤1：检查三段式应急编码（最高优先级，无需"小正"前缀）
    emergency_match = re.match(r'急停\s*(\d+)\s*急停', text)
    if emergency_match:
        return NlpResult(
            input_type="emergency",
            semantic_level=5,
            action="emergency",
            params={"emergency_type": "estop"},
            emergency_code=emergency_match.group(1),
            raw_text=text,
            confidence=1.0
        )

    # 步骤2：检查"小正"前缀
    if text.startswith(("小正", "小正，", "小正 ", "小郑", "校正")):
        command = re.sub(r'^小[正郑]|^校正', '', text).lstrip("，, ")
        input_type = "command"
    else:
        # 步骤3：检查危险词提及（不执行，只提示）
        danger_words = ["急停", "暂停", "复位"]
        for word in danger_words:
            if word in text:
                return NlpResult(
                    input_type="chat_with_warning",
                    semantic_level=1,
                    action="chat",
                    params={"warning": f"如需执行'{word}'，请说'小正，{word}'或使用三段式格式"},
                    emergency_code=None,
                    raw_text=text,
                    confidence=1.0
                )
        # 步骤4：闲聊
        return NlpResult(
            input_type="chat",
            semantic_level=1,
            action="chat",
            params={},
            emergency_code=None,
            raw_text=text,
            confidence=1.0
        )

    # 步骤5：同义表达归一化
    for synonym, standard in SYNONYM_MAP.items():
        command = command.replace(synonym, standard)

    # 步骤6：要素提取（正则匹配）
    params = extract_elements(command, memory)

    # 步骤7：确定语义层级
    semantic_level = determine_semantic_level(params)

    # 步骤8：确定动作类型
    action = determine_action(params)

    return NlpResult(
        input_type=input_type,
        semantic_level=semantic_level,
        action=action,
        params=params,
        emergency_code=None,
        raw_text=text,
        confidence=0.95
    )
```

# execution/func_mapper.py

def map_to_func(nlp_result: NlpResult, memory: MemoryParams = None,
                position_registry = None) -> Optional[FuncResult]:
    """将NLP解析结果映射为Func参数"""

    if nlp_result.action == "emergency":
        return _map_emergency(nlp_result)
    elif nlp_result.action == "joint_nudge":
        return _map_joint_nudge(nlp_result, memory)
    elif nlp_result.action == "virt_nudge":
        return _map_virt_nudge(nlp_result, memory)
    elif nlp_result.action == "cart_move_abs":
        return _map_cart_move_abs(nlp_result, memory)
    elif nlp_result.action == "io_control":
        return _map_io_control(nlp_result)
    elif nlp_result.action == "delay":
        return _map_delay(nlp_result)
    elif nlp_result.action == "work_position":
        return _map_work_position(nlp_result, position_registry)
    else:
        return None


def _map_virt_nudge(nlp_result: NlpResult, memory: MemoryParams) -> FuncResult:
    """虚拟轴增量运动 → Func107"""
    params = nlp_result.params
    axis_no = params["axis_no"]      # 6~11
    direction = params["direction"]  # +1/-1
    step = params.get("step") or memory.state.current_step_mm
    spd = params.get("spd") or memory.state.current_speed
    acc = params.get("acc") or memory.state.current_acc
    dec = params.get("dec") or memory.state.current_dec

    return FuncResult(
        func_id=107,
        ieee_dict={
            0: 107,
            2: axis_no,
            4: direction * step,
            6: spd,
            8: acc,
            10: dec,
            12: 1,    # fuzzy_pos=增量
            14: 0,    # fuzzy_spd=绝对
            16: 0,    # fuzzy_acc=绝对
            18: 0,    # fuzzy_dec=绝对
        },
        channel="motion",
        skip_echo_check=False,
        skip_status_check=False
    )


def _map_emergency(nlp_result: NlpResult) -> FuncResult:
    """应急指令 → Func104"""
    params = nlp_result.params
    emergency_type = params.get("emergency_type", "estop")

    if emergency_type == "estop":
        ieee_dict = {0: 104, 2: 1}   # 急停按下
    elif emergency_type == "pause":
        ieee_dict = {0: 104, 4: 1}   # 暂停按下
    elif emergency_type == "resume":
        ieee_dict = {0: 104, 4: 2}   # 暂停解除
    elif emergency_type == "reset":
        ieee_dict = {0: 104, 8: 1}   # 报警复位
    else:
        ieee_dict = {0: 104, 2: 1}   # 默认急停

    return FuncResult(
        func_id=104,
        ieee_dict=ieee_dict,
        channel="stop",
        skip_echo_check=True,   # 急停跳过回显校验
        skip_status_check=True  # 急停跳过状态检查
    )

import json, os

class PositionRegistry:
    def __init__(self, config: ConfigManager):
        self._positions = {}
        self._config = config
        self._load()

    def _load(self):
        """从配置加载位置库"""
        # 先尝试加载position_registry.json
        # 如果不存在，从query_table.json中提取位置定义
        qt = self._config.load_config("query_table")
        for record in qt.get("records", []):
            if record.get("func_num") == 108 and "target_x" in record.get("params", {}):
                name = record["query_key"]
                p = record["params"]
                self._positions[name] = PositionEntry(
                    name=name,
                    desc=record.get("description", ""),
                    x=p["target_x"], y=p["target_y"], z=p["target_z"],
                    rx=p["target_rx"], ry=p["target_ry"], rz=p["target_rz"],
                    spd=p.get("spd_pct", 30.0),
                    move_type=p.get("move_type", 1),
                    locked=True
                )

    def get(self, name: str) -> Optional[PositionEntry]:
        return self._positions.get(name)

    def save(self, name: str, entry: PositionEntry):
        self._positions[name] = entry
        self._save_to_file()

    def delete(self, name: str) -> bool:
        if name in self._positions:
            del self._positions[name]
            self._save_to_file()
            return True
        return False

    def list_all(self) -> list:
        return list(self._positions.keys())

    def _save_to_file(self):
        """保存到position_registry.json"""
        data = {}
        for name, entry in self._positions.items():
            data[name] = {
                "desc": entry.desc,
                "x": entry.x, "y": entry.y, "z": entry.z,
                "rx": entry.rx, "ry": entry.ry, "rz": entry.rz,
                "spd": entry.spd, "move_type": entry.move_type,
                "locked": entry.locked
            }
        path = os.path.join(self._config._config_dir, "position_registry.json")
        with open(path, 'w', encoding='utf-8') as f:
            json.dump({"position_registry": data}, f, ensure_ascii=False, indent=2)

7步握手核心逻辑，复用已有版本的system_config.json中的回显参数：

```python
# execution/modbus_writer.py
import time

class ModbusWriter:
    def __init__(self, config: ConfigManager):
        self._write_func = None
        self._read_func = None
        self._config = config

    def set_io_functions(self, write_func, read_func):
        self._write_func = write_func
        self._read_func = read_func

    def modbus_write(self, func_id: int, ieee_dict: dict,
                     timeout_ms: float = 5000,
                     skip_echo_check: bool = False,
                     skip_status_check: bool = False) -> ModbusWriteResult:
        t0 = time.time()

        # 步骤1: 写函数号
        self._write_ieee(0, func_id)

        # 步骤2: 写参数
        for addr, value in ieee_dict.items():
            if addr != 0:  # 0已在步骤1写入
                self._write_ieee(addr, value)

        # 步骤3: 回显校验
        if not skip_echo_check:
            if not self._echo_check(func_id, ieee_dict):
                return ModbusWriteResult(False, func_id, "回显校验失败", elapsed(t0))

        # 步骤4: 状态检查
        if not skip_status_check:
            if not self._status_check(func_id):
                return ModbusWriteResult(False, func_id, "状态检查未通过", elapsed(t0))

        # 步骤5: 触发
        self._write_ieee(32, 1)

        return ModbusWriteResult(True, func_id, "写入成功", elapsed(t0))

    def emergency_stop(self) -> ModbusWriteResult:
        """急停 - 跳过回显和状态检查"""
        return self.modbus_write(104, {2: 1},
                                skip_echo_check=True,
                                skip_status_check=True)

    def _echo_check(self, func_id, ieee_dict) -> bool:
        """读IEEE(280~312)回显区，确认数据正确写入"""
        retry_count = self._config.get("echo_retry_count", 3)
        epsilon = self._config.get("echo_compare_epsilon", 0.001)

        echo_func = self._read_ieee(280)
        if abs(echo_func - func_id) > epsilon:
            return False

        for addr, value in ieee_dict.items():
            echo_addr = 280 + addr  # 回显地址偏移
            echo_val = self._read_ieee(echo_addr)
            if abs(echo_val - value) > epsilon:
                return False
        return True

    def _status_check(self, func_id) -> bool:
        """读LONG(34)，检查全局状态"""
        long34 = self._read_long(34)
        # 检查：无报警(34.24=0)、无急停(34.25=0)、系统就绪(34.28=1)
        if (long34 & 0x1000000) != 0:  # M_ALARM
            return False
        if (long34 & 0x2000000) != 0:  # M_ESTOP
            return False
        if (long34 & 0x10000000) == 0:  # M_READY
            return False
        return True
```

# safety/emergency_channel.py
class EmergencyChannel:
    def __init__(self, writer: ModbusWriter, config: ConfigManager):
        self._writer = writer
        self._config = config
        self._whitelist = config.get("emergency_codes", [])

    def execute_emergency(self, code: str, emergency_type: str = "estop") -> ModbusWriteResult:
        # 步骤1：验证编码白名单
        if code not in self._whitelist:
            return ModbusWriteResult(False, 104, f"编码{code}不在白名单", 0)

        # 步骤2：直接调用MODBUS写入，跳过安全检查
        if emergency_type == "estop":
            return self._writer.emergency_stop()
        elif emergency_type == "pause":
            return self._writer.modbus_write(104, {4: 1},
                                            skip_echo_check=True,
                                            skip_status_check=True)
        elif emergency_type == "resume":
            return self._writer.modbus_write(104, {4: 2},
                                            skip_echo_check=True,
                                            skip_status_check=True)
        elif emergency_type == "reset":
            return self._writer.modbus_write(104, {8: 1},
                                            skip_echo_check=True,
                                            skip_status_check=True)

class ConfirmHandler:
    def handle_confirm(self, text: str, pending: dict) -> dict:
        """处理确认阶段的操作者回复"""
        cleaned = text.strip()

        # 确认执行
        if "确认" in cleaned or "执行" in cleaned:
            return {"action": "execute", "params": pending["params"]}

        # 取消
        if "取消" in cleaned:
            return {"action": "cancel"}

        # 修改速度
        speed_match = re.search(r'速度.*?(\d+)', cleaned)
        if speed_match or "速度降" in cleaned or "加速" in cleaned:
            new_params = pending["params"].copy()
            if speed_match:
                new_params["spd"] = float(speed_match.group(1))
            elif "降" in cleaned:
                new_params["spd"] = new_params.get("spd", 50) - 10
            elif "加速" in cleaned:
                new_params["spd"] = new_params.get("spd", 50) + 10
            return {"action": "modify", "params": new_params}

        # 默认：重新复述
        return {"action": "reconfirm"}

# pipeline.py
class Pipeline:
    def __init__(self, config_dir: str):
        # 初始化所有模块
        self.config = ConfigManager(config_dir)
        self.memory = MemoryParams(self.config)
        self.history = MotionHistory()
        self.json_msg = JsonMessage()
        self.nlp = ...  # M3
        self.func_mapper = ...  # M4
        self.position_reg = PositionRegistry(self.config)  # M8a
        self.flow_reg = FlowRegistry(self.config)  # M8b
        self.logger = DialogLogger()  # M12
        # M1/M2/M5/M6/M11 需要MODBUS连接后初始化

    def process_input(self, text: str, input_type: str = "text") -> dict:
        t0 = time.time()

        # 步骤1：回执应答
        ack = ReplyTemplate.build_ack(input_type)

        # 步骤2：NLP解析
        nlp_result = classify_input(text, self.memory)

        # 步骤3：应急通道
        if nlp_result.semantic_level == 5:
            result = self.emergency_channel.execute_emergency(
                nlp_result.emergency_code, nlp_result.params.get("emergency_type"))
            return self._build_response(ack, nlp_result, exec_result=result)

        # 步骤4：Func映射
        func_result = map_to_func(nlp_result, self.memory, self.position_reg)
        if func_result is None:
            return self._build_response(ack, nlp_result, error="无法映射为Func")

        # 步骤5：默认值补全（已在M4中完成）

        # 步骤6：L1安全检查
        safety_result = self.l1_precheck.check(func_result, self.dashboard)
        if not safety_result.passed:
            return self._build_response(ack, nlp_result, func_result, safety_result)

        # 步骤7：确认模式判断
        if self._need_confirm(nlp_result, safety_result):
            return self._build_confirm_response(ack, nlp_result, func_result, safety_result)

        # 步骤8：MODBUS写入
        exec_result = self.modbus_writer.modbus_write(
            func_result.func_id, func_result.ieee_dict,
            skip_echo_check=func_result.skip_echo_check,
            skip_status_check=func_result.skip_status_check)

        # 步骤9：结果反馈
        return self._build_response(ack, nlp_result, func_result, safety_result, exec_result)
